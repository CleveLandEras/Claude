## 2. Lemo-Opuscar

**对应仓库：lemomo-ai/lemo-opuscar**，https://github.com/lemomo-ai/lemo-opuscar

注意：felo.ai 开源许可页写的是 LemoLab/lemo-opuscar，这个地址访问返回 404（2026-11-02）。仓库里插件安装命令用的市场名是 lemolab，但 lemomo-ai 和 LemoLab 的关系没有核实，请号主确认。

1. 它是什么：作者 lemomo-ai，10,612 星，1,218 分叉，MIT 许可（代码和文档），最近推送 2026-10-31。
2. 里面有什么：给 Claude Code 用的代码风格工具箱，官方写 66 个现成风格，支持自定义。每个风格是「风格提示词加一支代码做的示例短片」，不是 Remotion 工程，也不是成片合集。示例包括浮世绘、水彩笔刷、瑞士动态图形、HD-2D 等。作者称示例短片全部由 Claude Opus 5.5 写代码完成，没用视频模型。默认配音是 Kokoro（本地开源 TTS）。
3. 对我们有没有用：有用。66 个风格的提示词可以直接扩充画风测试，Kokoro 本地配音也符合我们不开第三方账号的规则。但它以 Claude Code 插件形式安装，装之前要先读源码，不能直接运行。示例短片和图片为 CC BY 4.0，其中三条配音轨道不在此许可内，复用前要查。

## 3. pdoom-video

**mexicat/pdoom-video**，https://github.com/mexicat/pdoom-video

1. 它是什么：作者 mexicat，3,693 星，422 分叉，代码为 MIT 许可；音乐和歌词不在许可范围内，归原作者。最近推送 2026-10-05。
2. 里面有什么：代码渲染的音乐视频工程，不是 Remotion 工程，也不是提示词合集。画面用 TypeScript 和 three.js，bun/Vite 构建。音频分析用 Python（uv）：Demucs 人声分离、CTC 强制对齐（用 Whisper 交叉核对）、节拍和起音检测。离线导出用 headless Chrome 加 ffmpeg。README 写视频是用 Claude Code 中的 Claude 做的，这是作者自述。
3. 对我们有没有用：有参考价值，主要用在 beats.py 上。它的思路是每一帧都是时间的确定函数，所以预览和导出一致；节拍和起音检测可以对照。代码不能直接搬用，音乐和歌词不能复用。

## 4. mg-styles-15

**Vincentwei1021/mg-styles-15**，https://github.com/Vincentwei1021/mg-styles-15

1. 它是什么：作者 Vincentwei1021，2,814 星，357 分叉，MIT 许可，最近推送 2026-10-05。
2. 里面有什么：15 个动态图形风格，每个风格是一支 10 秒短片，配一份提示词（prompts/ 目录）。提示词让 Claude 写代码生成视频。另有 rubric.md（评审标准）和 template.md（写新风格的模板）。风格包括线条抖动、等距 2.5D、扁平矢量、线稿、3D 渲染、形状变形、贴纸讲解、赛博朋克 HUD、拼贴、极光玻璃、包豪斯几何、80 年代合成波、像素画、流体、字幕变体。技术上用 SVG、Canvas、WebGL、Three.js，3D 那支用 Blender，headless Chrome 截帧，ffmpeg 合成，Python 生成配乐。
3. 对我们有没有用：最直接。15 个风格的提示词可以扩充画风测试；rubric.md 可以和我们的 7 维评分对照。README 里的 AI 评审分数（7.57 到 8.21）是作者自报，不作依据。

## 5. ClaudeAnimationBase

**JohnHeibel/ClaudeAnimationBase**，https://github.com/JohnHeibel/ClaudeAnimationBase

1. 它是什么：作者 JohnHeibel，2,402 星，217 分叉，MIT 许可，最近推送 2026-09-24。
2. 里面有什么：代码工程，不是提示词合集，也不是成片。用 p5.js 和 p5.brush 画手绘卡通，角色叫 Clawd，有 31 种表情、动作辅助和转场系统。ANIMATION_GUIDE.md 是写给模型的规则。headless Chrome 渲染，输出接触表、帧条和 MP4，让模型自己检查成果。需要 Node.js、Chrome、ffmpeg。
