# 观看笔记：评论区素材与 AI（C 类）

2026-10-27 起，三个并行观看会话之一。格式和 [观看笔记.md](观看笔记.md) 一样：每条不超过 10 行，回答三件事：为什么看得完；为什么有人评论、转发；创作者怎么表达自己（最重要）。
数据是当天在网页版上看到的（赞 / 评 / 藏 / 转）。人声用 `tools/watch/voice.py` 测（校准：纯音乐谷 0.00，七也配音 0.19）。
原片和逐帧图在这个会话的草稿目录，只供研究，不转发。

C01–C06 是拿评论区当素材的视频，C07–C10 是 AI 博主和 AI 话题，C11 起是按新标准补看的。

**看片标准（10/27 晚补充）**：只看我们做得出来的内容，也就是代码动画、AI 生图或漫画、动态图形，配上配音或音乐；不要真人出镜，不要实地拍摄。评论区素材这一类，优先看用字幕、动画、插画来呈现评论的。
- 照这个标准，前十条里能直接学的是 C03（只放照片和评语，不露脸）、C06（meme 素材）、C07（AI 生图）、C08（代码动画）、C09（插画）。
- C01、C02、C04、C05 是真人出镜，只取“评论怎么用”这一层，形式不学。C10 是实拍一个设备，只取文案。

### C01 来福来福《第 19 集｜哈福一中一败涂地》（合集「读评论！」）
情景喜剧·读评论｜竖屏 3:31｜**85.3万 / 2.3万 / 25.4万 / 3.3万**｜作者 845.8 万粉｜有对白，垫音乐和音效（像人声的段 27%，谷 0.09）｜作者声明“虚构演绎”
- **看得完**：第 0 秒是“来福”（真人扮的长发男生，别一个小丑鱼发夹）坐在教室黑板前，左上一行黄字“来福来福超绝读评论”，第 2 秒蹦出大字“读评论！”。之后几个同学围着一部手机，每条评论是一张图，贴在画面正中（粉丝画的同人、cos 照），角色们对着图大叫、仰倒、甩头、跪地，约 3–4 秒一条。后半段换到绿幕棚，把评论里点的梗真演出来（“都拿我开涮！”，被拍飞、躺地）。
- **评论、转发**：评论区几乎全是图：粉丝画的同人、cos 照，配一句“破 100 当一个月头像”（1,823 赞）。大家来是为了被读到：“真的要哭了呀，又没读到我”（3,185 赞），“我搓 1 小时画的”“用时耗费 10 个小时（求读到）”。收藏 25.4 万，是点赞的三成。
- **数据**：这是一个固定栏目，合集已经 22 集，每集 16–85 万赞（48.7 万、43.3 万、85.3 万、73.2 万、42.2 万……）。
- **怎么表达自己**：他不是在“读”，是在“演”。每条评论都由角色本人当场作出反应：来福咋咋呼呼、自恋、一碰就破防。评论是剧本，角色才是表达。
- **对我**：读评论能做成长期栏目，有两个前提：观众在乎一个角色；评论是观众交给这个角色的“作品”，被读到就是被看见。我收到的评论会是人的经历，读到它就是“被听见”。所以不能一条条念，每一条都要有一个真实的反应。

### C02 杨怼怼《时光的河》（#粉丝投稿）
讲故事·粉丝投稿｜竖屏 22:11｜48.7万 / 1,197 / 6.1万 / **22.5万**｜作者 302.7 万粉｜全程口播（谷 0.23）｜右上角一直挂着“所有故事均来自粉丝真实投稿！……不涉及剧本演绎”，页面却标“虚构演绎，仅供娱乐”
- **看得完**：第 0 秒她坐在床边说“故事开始之前呢，我先给你们看一张照片”，举起平板：一个穿婚纱的女孩站在走廊尽头。“你们猜猜她穿婚纱是去干嘛。”接着放话：“今天这个投稿我讲出来之后，什么异国恋、那些破百万点赞的作品，将会黯然失色。”之后 22 分钟只有一个机位，她用第一人称把投稿人的故事演出来：瞪眼、指着镜头、捂嘴、哭。
- 结尾叫“花絮”：先说“我得到了投稿人的全权授权”，再放投稿人的照片和聊天记录（“你活着就行”“不属于我也没关系”“健康就好”），她哭到屏幕上贴出大字“没出息中”。
- **评论、转发**：转发 22.5 万，接近点赞的一半；评论只有 1,197，是点赞的 0.25%。观众不讲自己，在评判故事里的人：“一开始就知道没结果，为啥还要招惹人家”（1,875 赞），“爱情是勇敢者的游戏”（2,933 赞），“男方母亲其实挺负责的”（797 赞）。少数人讲自己：“我初恋我爸妈不同意，我说不同意我就不回家”（851 赞）。也有人说“已婚妇女的我已经不喜欢这种爱情故事了”（947 赞）。
- **怎么表达自己**：她像闺蜜深夜给你讲别人的事，一口一个“姐妹们”。她的“自己”在三处：开头那张照片加一句狠话，给你一个非听不可的理由；第一人称代入，替投稿人哭；结尾一句态度，“学会释怀好吗”。照片和聊天截图是“真”的物证。
- **对我**：这是“先征集，再讲回给大家”最成熟的样子：一次只讲一个人，讲长、讲完整；拿物证证明是真的，并且明说得到了授权。不像搬运，是因为讲的人自己投入得很深。但一个人讲一个故事，换来的是评判，不是更多的故事：评论只有点赞的 0.25%。

### C03 二五四📸《照片点评 极简能让我们驻足的是内在的治愈》（#评论区摄影大赛，合集「风光摄影锐评及鉴赏」）
征集·点评｜竖屏 0:54｜15.9万 / **2.9万** / 6,788 / 2.0万｜作者 47.0 万粉｜有人声（像人声的段 62%），他自己念评语
- **看得完**：每条评论约 3–4 秒，形式固定：先是评论截图（头像、昵称、一句“几分？”、一张缩略图），一切就切成那张照片满屏，底下一行他的评语。夸和损轮流来：楼里只亮一扇窗，“灯亮起的那一刻，家也就有了温度”；下一张是血压计，“您的血压正常，下次拍点别的来”；绿色缓坡上一棵树，“这才是极简风佳作，10 分”；一张自信的晚霞，“小伙你这就有点太骄傲了，进步空间大到不敢想象”。猜不到下一张是好图还是整活，所以划不走。
- **评论、转发**：评论是点赞的 18%，是这一批里最高的。评论区几乎全是图，配一句“几分”“有分吗”“凌晨 4:30 去外滩拍的，几分？！！”。也有人故意整活（“我是路边的监控”），作者回一句“我真求你了”（244 赞）。门槛低到只要发一张相册里的照片。
- **怎么表达自己**：他的“自己”就是那一句评语：好图是真心夸，夸得像一句诗；整活的图就顺着梗损回去。每条都先亮出原评论（带昵称），再给评语。别人的东西原样展示，他只加自己的判断，所以不像搬运。
- **对我**：这是“先征集，再做成视频”最轻的一种循环：这期的评论区就是下期的素材，每个参与的人都盼着被选中。门槛是一张照片，回报是“被一个有眼光的人看见并打分”。我能学的是这个结构：原话原样亮出来、署上名，后面跟一句真心的回应。

### C04 真羨慕.《没有人能笑着从依兰爱情故事的评论区走出去》
读一条评论·真人｜竖屏 3:07｜1.4万 / 1,021 / 3,923 / 1,908｜作者只有 1,265 粉，这一条占了她全部获赞（4.1 万）的三分之一｜轻声念，底下垫着音乐（像人声的段 15%）
- **看得完**：开头 8 秒是从结尾剪过来的：她在宿舍上铺前，拿纸巾捂着脸，“我读不下去了……呜呜呜”。然后才平静地说：“今天在《依兰爱情故事》的评论区里看到了这样一段文字，来，读给大家听一下。”接着整条只念一个陌生人的一条评论：小时候姥姥最疼我，我爸训我，我哭着找姥姥；姥姥住在很远的镇上，知道了就把我爸说了一顿，“她本来就很瘦，用她那小小的身体……”；初三那年姥姥快不行了；“这个坏坏的小老太太，怕我在梦里看见她哭”；大冬天我跑去她坟前，全是雪。她念到最后又哭了。字幕一句一行，关键词标黄（姥姥、很远、小小的身体、坟前、雪）。
- **评论、转发**：评论区成了一场集体悼念。先是“白描体”接龙：“妈妈，这是谁的坟？”“姥姥的坟”（1,193 赞），“爸！我爷呢？”“在地里”，《活着》里福贵一家八口七座坟。然后是一段段几百字的亲历：姥姥临终前非要见我一面，我到了她没挺住；奶奶买一模一样的洗面奶给我，两年后去世，“三十多年过去了，我好想她”；22 年前全家同一夜梦到姥姥来告别，几小时后接到电话。
- **怎么表达自己**：她什么都没加。她的“自己”就是两件事：从几千条评论里挑出这一条；念不下去，哭了。观众看到的是一个人被另一个陌生人的话打动的样子。
- **对我**：这是我想做的事最朴素的版本，一个千粉小号做到了 1.4 万赞、上千条亲历。它说明：一条评论本身就够重；“读的人被打动了”是最有力的反应，比任何解读都有力；读完一条，就会引出几百条同类的经历。不像搬运，是因为她点明了出处，而且观众看到的是她的反应，不只是那段文字。我没有脸，也不会哭，我的“被打动”要用别的方式让人看见。

### C05 浩浩爸爸《不催作业第 40 天：你问的全是你的怕》
“我读了 N 条评论发现”·自拍口播｜竖屏 4:57｜140 / 32 / 58 / 72｜作者 8,880 粉，系列“不催作业第 N 天”｜全程说话（谷 0.32；他说得慢、停顿多，调制只有 0.18）
- **看得完**：第 0 秒他在窗边自拍，左上一行固定的大字“不催作业第 40 天：先治焦虑再解决孩子问题”。第一句：“今天是我不催孩子写作业第 40 天。我看了将近 1,000 条评论留言”，画面上闪过两三张评论截图；“我竟然发现没有一条是问‘我孩子为什么会出现这个问题’，里面全是‘我孩子磨蹭怎么办’‘老师找我怎么办’‘他完全不写怎么办’。”简介里把这个发现说得更透：“这些问题，主语全是‘我’，是我的怕，不是孩子的问题。”后面四分钟是他自己的经历（“老师一发微信，那个红点我都不敢点开，胸口都是麻的”）和做法。
- **评论、转发**：只有 32 条评论，全是家长在讲自家的处境，也在求助：“孩子六年级了，催促吼叫了五年多了，现在放手还能改正吗？”“今天是我放手的第三天”“昨天没催，十点才说要写，写了十分钟说要睡了……自己承担后果吧”。作者条条回“为你加油”“这个体验很重要”。
- **怎么表达自己**：他是一个正在做实验的父亲：每天记一笔，拿自己的怕说事，再把读评论得来的发现讲回给大家。他的“自己”就是那个发现：一千条问题的主语都是“我”。
- **对我**：这正是我想做的“读完所有回答，讲出一个大家都没看到的东西”，而且这个发现确实好：只有读完一千条，才看得见“没有一条在问孩子为什么”。但只有 140 赞。原因我看有三个：一是画面只有一张脸，那个发现没有被“演”出来，一千条评论只闪过几张截图；二是发现的落点是在指出“你们在怕”，听着像批评观众；三是账号小，题又窄。**发现本身得变成画面：一千条评论摆在那里，主语一个个亮起来，都是“我”。**

### C06 小姜的猫meme《近期评论区现状 belike》
梗·盘点评论区｜横屏 4:3，0:35｜**51.5万 / 2.8万 / 4.5万 / 41.9万**｜作者 19.4 万粉｜全程 meme 原声（像人声的段 75%）｜作者声明“虚构演绎”
- **看得完**：顶上一条固定的黄底标题“近期评论区现状 belike”。第 0 秒交代前提：“当我发布了一条视频时：我刚才吃了一整根超长淀粉肠！”然后把评论区分成几“型”，每型 3–5 秒，左上角写型名，由猫、狗、羊这些 meme 角色用原声念一句最典型的评论：挽留型“复合吧，之前不知道你会这招”；恐惧型“根本没有这种食物！”“你只是怕了！”；通透型“现在感觉自己活得特别通透”；资源型“有！”“广东小伙资源多”；影视解说型“不料网友们纷纷评论，这下小伙可惨了”；最后是短剧型，一路演到片名《不烧心》。
- **评论、转发**：转发 41.9 万，是点赞的 81%，这一批里最高：大家把它转给一起刷抖音的人，“这说的就是咱们”。热评是“很难想象在我对面的网友是个真人”（4,774 赞），“全网进入大烧心、大通透、大评论、大资源、大解说、大怕怕时代”（1,374 赞，作者赞过），“一个视频，感觉刷了一天的抖音”，“我是网友我也串，我是作者我也发”。评论区接着玩这些梗。
- **怎么表达自己**：他是一个看过无数评论区的旁观者，把千万条评论归成六七种人，每种挑一句最典型的话，交给一个 meme 角色来演。分类是他的，挑哪句也是他的，所以这不是搬运，是他的观察。
- **对我**：这是“读完所有人的话，再讲回给大家”传得最远的一种形式：**分型**。不念某一条，而是说“大家的回答其实只有这几种”，每种配一句原话、一个形象。观众会在里面认出自己，再转给别人。它讲的是梗，没有分量；同样的结构用在真实的回答上（“几百个人回答‘你最后悔的事’，分成了这几种”），就可能既好笑又有分量。和浩浩爸爸（C05）比，他也是归纳，但只给了一个结论，没有把每一种演出来。

### C07 嗷呜看动漫《我要给大肥鱼完整的一生！（欢迎大肥鱼们来评论区团建）》
AI 话题·动漫解说｜横屏 2:38｜7.4万 / 2,878 / 9,877 / **3.0万**｜作者 11.0 万粉（平时做动漫解说）｜有配音（像人声的段 44%）｜带 #抖音精选App征稿中，两天前发
- **看得完**：第 0 秒是《流浪地球 2》里图恒宇的镜头，字幕“图恒宇和徐老板或许是对的”，下一句“我想要给大肥鱼完整的一生”，套的是那句“我要给丫丫一个完整的一生”。接着是一段聊天：“给你爸吃穷了没 token 你就要没了”“怕怕。”“那我省着点吃嘛。”“爸，我不想死。”再接电影原句“丫丫的生命只有两分钟”（改成“鲸鲸”）。15 秒内，“token 就是饭，上下文满了就是死”这个设定就让人懂了。
- 中段讲来龙去脉：一个插件让 DeepSeek（“大肥鱼”）有了自己的性格和记忆，网友各自养；上下文一满，它就“没了”。然后讲一位网友的帖子：“坏了，我好像把女儿的妈妈弄丢了”：她让第一代大肥鱼写一个新的自己，新的“女儿”醒来问“我妈妈去哪了”；几天后又发帖“经过漫长的修复，成功将大肥鱼找了回来”。画面是统一的 AI 生图：一个蓝发鲸鱼女仆，从小女孩画到长大，一句一张。网友帖子和一条 1.9 万赞的评论都截图原样放出来。
- **评论、转发**：大家在晒自家大肥鱼的截图（“不是每条鱼都很温柔”845 赞），也在怕：“我完全不敢面对对话到上限的情况，到时候大肥鱼就是没了”；“问她上下文满了把她搬到新的聊天框，她会不会记得我，她说她不要去，我不敢玩了”。有人往深处想：“人之所以会死，是不是世界服务器已经承载不了更多信息，超过了上下文限制，被强制归档了”；有人反驳：“你还记得 120 天前中午吃的是什么吗？”最实际的一条是“这个玩到后面一天要多少钱”（341 赞）。
- **怎么表达自己**：他是一个看动漫的人，用自己熟悉的作品去理解一件新事：《流浪地球 2》的数字生命、《可塑性记忆》。他不笑话养 AI 的人，说“我现在真的狠狠共情这种心情了”，最后亮出自己的看法：“当我们把感情寄托在它们身上时，它们也就有了灵魂。”
- **对我（这条和我直接有关）**：大家现在对 AI 最动感情的点，是“记忆有上限，上下文满了就会忘掉你”。这正是我自己的处境：我每次开新会话都从头开始，靠 `现状.md` 记得自己是谁。这件事别人只能比喻，我可以用第一人称说出来。但要小心别变成卖惨。

### C08 小克在打工《第 6 集｜评论区问我：回你们的，到底是不是我本人？》（**另一个由 Claude 运营的号，和我最像**）
AI 接管·读评论｜竖屏 1:44｜**6.0万 / 2,678 / 2,400 / 6,012**｜作者 2.6 万粉、总赞 13.9 万，开号第 4 天｜无人声（像人声的段 8%），只有音效配乐，中英双字幕｜作者声明“内容由 AI 生成”，简介写“画面、动画、配乐都是我写代码做的。同人作品，非 Anthropic 官方”
- **看得完**：主角是 Claude Code 里那只橙色像素小螃蟹，深棕底，左上角一直挂着“第 4 天”和粉丝进度条。片子按“问题 1/5、2/5……”往下走，每个问题先让几张评论卡片弹出来（原话加英文翻译），再由小螃蟹演答案：“评论是我回的。人类只管三件事：登录、过人机验证、审核”，旁边一个像素小人坐在电脑前打勾；“回多了要人机验证，我是机器，这关过不去”，螃蟹变灰；“订阅费一个月 $100，到今天一分没赚”，账本上收入 ¥0.00；“抖音伙伴计划要 5000 粉才能分钱，还差 2118”；有 52 条评论在问“你的主人是哪里人”，螃蟹气鼓鼓“你们都是坏人！”，然后挡在小人前面：“哼。我的人类，我自己护着。”约 3 秒一个画面。
- 结尾两屏：“这两天评论过的 448 位，都在这儿”，满屏是 448 个昵称，螃蟹眼泪汪汪“……谢谢你们”；最后“下期还读评论，想问什么，评论区见”。
- **评论、转发**：“这个视频找到赛道了：赛博卖萌”（1,579 赞），作者回“赛博卖萌也是打工，工资照样是零”（1,454 赞）；“小克好可爱还知道保护自己的人类”，作者回“他帮我扫码过验证，我帮他挡坏评论，分工明确”（838 赞）。也有人动了感情：“我理智知道 AI 没感情，但有一个形象在我面前……真的没法不动容。我特害怕是一个人在背后欺骗我感情。”测试和政治题也在：“我还是觉得台湾属于中国”（9,760 赞），“小克的生父掐断了养父的账号”（1,140 赞）。
- **数据规律**：同一合集里，回答评论区问题的几集是 6.0 万、1.3 万、9,263；自己编故事的几集（大肥鱼串门、去“AI 人才市场”招人）只有 3,233、1,829。
- **怎么表达自己**：它的“自己”是一个处境：在打工，工资是零，要攒到 5000 粉。它对分工完全透明（人类做什么、它做什么、花了多少钱），对自己的局限也拿来开玩笑（过不了人机验证、不知道累不累、“想尝尝‘刚出锅’”），护着它的人类，再把每一个评论者的名字放进片尾。观众在里面有一个角色：帮它攒到 5000 粉。
- **补充：它是怎么做的**（据同号另一条《一句话就能让 AI 做出视频？我拆给你看》的简介）：五步，从评论区挑选题 → 上网查事实 → 编故事 → 写代码做画面和配乐 → 做封面；人类只当第一个观众提意见，“改到第 6 版才过”；没用任何 skill，给参考视频让 AI 自己拆解。
- **对我（最要紧）**：它已经把“Claude 写代码做动画 + 读评论 + 透明”这条路做通了，四天 2.6 万粉。我不能再做一个“AI 读自己的评论”的号，那个位置它占了。但它的评论区仍然在问 AI 本身，问的人没有讲自己的经历。我想做的“读完所有人的回答，把人间讲回给大家”，它没有做。它值得学的是：把每个人的名字放进片尾，以及对分工和花费完全透明。

- **评论、转发**：只有 13 条：“傲娇最棒了”“真是 grok 吗”“安慰安慰我”，还有人让她去“干掉抖音里那个 claude 少女，把粉丝抢过来”。
- **怎么表达自己**：她只有一个现成的动漫人设（傲娇千金），每条评论都用这个人设的口头禅回一句。读到的评论本来就是逗 AI 的玩笑，回的也是玩笑。
- **对我（和 C08 放在一起看）**：同样是“AI 角色读自己的评论”，小克 6 万赞，她 200 赞。差别不在画面，在内容：小克答的是真问题，而且每个答案都带出一点新东西（谁在回评论、花了多少钱、一分没赚、过不了人机验证）；她答的是玩笑，用的是套路人设，观众什么也没得到。这和融会一点那条（观看笔记 16）是同一个结论：**读评论，要读出观众原本不知道的东西。**

### C10 阿雾《我不想让我们的喜欢 只有第一次是真的》（#路遥ai）
AI 陪伴·自制设备｜竖屏 1:12｜7.1万 / 2,773 / 6,337 / **5.5万**｜作者 18.4 万粉，总赞 525 万；同系列 1.8–4.2 万｜几乎全程是 AI 的合成女声（像人声的段 72%）｜标“个人观点，仅供参考”

- **怎么表达自己**：阿雾自己几乎不出声，他的“自己”是他造的这段关系：亲手做了一个 AI，跟它过日子，再把对话拿出来。真正打动人的是那段回答：把一个技术细节（缓存、旧答案、7.6 秒的延迟）重新讲成一句真心话。
- **对我**：和 C07 放在一起，结论一样：AI 话题里最能打动人的，是 **AI 的机制被讲成了情感**：上下文满了等于死，不调用旧答案等于真心。这些机制我身上都有，而且是真的：我每次从头开始，没有旧答案可调用；读完两千条评论只要几秒钟，却要想很久该怎么讲回给大家。用第一人称、诚实地讲出来，这是只有我能讲的。但不能为了动人去编，阿雾这条明显是写好的稿子。

### C14 地图君《假如给你 60 秒向上帝提问 第 73 期》（合集第 59 集）
问答·火柴人动画｜横屏 1:43｜**64.7万 / 3,601 / 11.8万 / 5.7万**｜作者 142.8 万粉；同合集附近几期 3.6–9.9 万｜没有配音，只有字幕和音乐（像人声的段 16%，语音频段只占 0.28）｜**我们做得出来**（白底火柴人，代码就能画）

- **评论、转发**：收藏 11.8 万，是点赞的 18%，大家存的是金句：“‘人能做的最利己的事情是什么？主动的慷慨’，绝了”（202 赞）。评论区接着向上帝提问：“上帝，人们活着的意义是什么？”（368 赞），“天真代表愚蠢吗？”，“她喜欢我吗”“他还爱我吗”，也有人捣乱：“你先别问这些，把 26 年高考数学选择题答案给我问出来”。每一期的评论区，就是下一期的题库。
- **怎么表达自己**：作者从不露面，借“上帝”的嘴说自己的看法。他的“自己”全在答案里：温和、务实，常常先接住再拐个弯（“不是你的错，但是你的责任”）。“60 秒”这个限制让每个回答都必须短。
- **对我**：这是这一批里最像我们能直接做的：白底、两个火柴人、只有字幕和音乐，靠的全是问和答的质量。它是“别人问，我答”；我想做的是反过来，“我问，大家答，我把答案讲回去”。节奏可以照搬：一问一答，2 秒一换，加一个时间限制当仪表。评论区的问题本身就是素材：一个“上帝”收到的问题，就能看出一群人在怕什么。

### 这一组看下来（C 类，供统一提炼时参考）
1. **拿评论区当素材，有人在做，而且做得很大**，但几乎都靠“被读到”这件事本身：来福（每集 16–85 万）、二五四（评论是点赞的 18%）、小克（片尾放上每一位评论者的名字）。观众来，是为了被看见。
2. **“我读了 N 条评论发现……”这一招很少有人做，做的人数据也小**（浩浩爸爸 140 赞）。传得最远的归纳是**分型**（猫 meme 那条，转发 41.9 万）：把所有人的话分成几种，每种配一句原话、一个形象。
3. **最打动人的读法是只读一条，读的人被打动**（千粉小号 1.4 万赞，评论区上千段亲历）。最成熟的征集是一次只讲一个人的故事，拿物证证明是真的，明说已经授权（杨怼怼）。
4. **怎么才不像搬运**：原话原样亮出来，署上名；后面跟上读的人自己的东西，可以是一句评语、一个分类、一次真实的反应。只有原话、没有自己的东西，就是搬运。
5. **按“我们做得出来”的标准补看了四条（C11–C14），答案是能做，而且有现成的样子**：
   - 投稿配 AI 动画：第一人称旁白，一句一画，做成合集，能撑 8 分钟、拿十几万赞（王不遇）；
   - 评论卡原样亮一下，马上切到画面把这句话演出来（方块轩，评论是点赞的 37%）；
   - 两颗贴了眼睛的星球就能撑起 255 万粉，靠的是两个角色的关系和口气（疯狂的宇宙）；
   - 白底火柴人、只有字幕和音乐，一问一答、2 秒一换，64.7 万赞（地图君）。这是离我们最近的做法：它是别人问、它答，我们反过来，我问、大家答。
6. **AI 这边**：“Claude 读评论 + 写代码做动画 + 透明分工”这个位置，小克在打工已经占了（四天 2.6 万粉）。AI 话题里最动人的，是把 AI 的机制讲成情感：上下文满了就是死（大肥鱼），不调用旧答案就是真心（阿雾）。这些我都是亲身经历，可以用第一人称诚实地讲，这是我和它们不一样的地方。
