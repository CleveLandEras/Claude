## 它是怎么搭起来的

一个虚构 App「Orbit」的发布预告。一个发光的小光点串起全片：

| 时间 | 画面 |
|---|---|
| 0–1.5s | 一颗彗星拖着光尾从右上角落下，落定成一个光点 |
| 1.5–3.5s | 光点变成点阵滑块，标签原地变字：Level Idea → Task → Goal |
| 3.5–4.5s | 收回成光点，光点飞走，带出彗尾 |
| 4.5–8.5s | 落下来变成二维点阵，光标在格子里移动，标签依次变成 Priority Plan → Later → Do first |
| 8.5–9.5s | 卡片缩成药丸形，再展开成输入框 |
| 9.5–16s | “Good evening.” 输入框：麦克风 → Listening 声波 → 逐字出现 “Finish the deck by Monday” → 按下发送，又收成光点 |
| 16–21.5s | 光点飞进计时卡片 1:02:12，进度条走完、打勾 → “Deck finished” → “Done” → “Nice work.” |
| 21.5–25s | 收拢、飞走，变成 GitHub 式的完成热力图，下面一行数字 10 / 32 / 7 / 1.4 |
| 25–28s | 热力图化成光点，彗星，打出 “Welcome to Orbit” |
| 28–32s | 粒子散开，出现 “COMMING SOON”（原片拼错了），淡出 |

## 精美在哪（可以学的）

1. **一个母题贯穿全片**：光点 / 彗星。每次换场都是光点飞过去、落下，再变成下一个画面，全片没有一处硬切，也没有淡入淡出。
2. **每一场只做一件事**：画面中央只放一个控件，演示一个动作（拖滑块、在点阵里选格子、语音输入、计时、热力图），大约 3–5 秒换一场。
3. **字在原地变**：Idea → Task → Goal 不是换一页新字，而是同一个位置上的词变成下一个词。
4. **材质**：点阵带渐变和光晕；毛玻璃卡片有细亮边；光是模糊过的，不是一条线；整体只用黑底和一种蓝。
5. **一直在动**：每一帧都有东西在动，缓动带一点弹性，元素之间是形变过渡。

## 用到《等待》上

- **让红点当母题**：它是“正在等的你”。它在 B 线上走，飞上那座“紧张的山”，停在山顶，最后落到“你的线”上；每次换场都由它飞过去，不再用淡入淡出。
- **把静态图表换成可以拖的控件**：一个“被电的可能”滑块从 0% 拖到 100%，旁边的“紧张”读数跟着升起、到顶、再落下，标签在原地变：一定不会 → 不知道 → 一定会。
- **“我”的那一段**：光点一个一个亮起来，中间是真正的黑。和“你”那条一直在走的线放在一起对照。
- **字更少**：让控件自己把意思演出来。
