# 能不能照着做：苹果、安卓四家、微信、支付宝的官方查看和关闭路径

查证日期：2026-11-02。只认厂商和支付平台的官方帮助页，网上教程、问答站一律不用。我没有在真机上走一遍这些路径，表里的路径都是官方页面上的原话或概括，页面本身没写的系统版本我一律写“页面未写”，不替它补。这个文件里“可靠程度”一栏都是官方帮助页，档位是“官方文件”；核不准的单独列在“核不准”一节。

## 结论一句话

苹果、华为、微信、支付宝四处有官方可照做的路径；小米、OPPO、vivo 三家没找到面向用户的官方“订阅管理”帮助页，只能写“核不准”，这三家手机上的订阅最稳的办法是回到扣款渠道（微信、支付宝）和应用本身去关。

## 可以照着做的检查顺序（由上面官方路径拼出来的，不是哪个官方页面的原样）

1. 扣款来自哪个渠道，先看账单：微信支付账单、支付宝账单、银行卡或信用卡账单、邮箱里的“Apple 提供的收据”。
2. iPhone：设置 → 姓名 → 订阅。
3. 华为（HarmonyOS 5.0 及以上）：设置 → 华为账号 → 付款与账单 → 订阅；更早的系统：付款与账单 → 自动续费。
4. 微信：我 → 服务 → 钱包 → 支付设置 → 自动续费、免密支付。
5. 支付宝：我的 → 设置 → 支付设置 → 免密支付/自动扣款。
6. 小米、OPPO、vivo：没有核实过的系统层入口，走第 1、4、5 步和应用自己的“会员/订阅”页。
7. 取消只管下一期，已经扣的钱要找商户（华为页写“确认取消后下个周期将不再扣费”；支付宝页的意思是解约要找签约商户办理）。向 12315 投诉的渠道出自规则.md 里的新闻报道，不是这几个帮助页的内容。
