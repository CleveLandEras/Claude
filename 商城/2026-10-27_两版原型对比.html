活动入口两版原型

合并版好康并入限时活动

玩家去哪找活动右下「活動中心」一个窗口，三个页签：遊戲活動｜平台活動｜好康；公告在右上菜单「公告訊息」
入口数量大厅 2 个活动与商城入口：左下「銀行」、右下「活動中心」；公告在右上菜单；底栏另有重点活动常驻入口
储值类活动在哪「活動中心」的「好康」页签；礼包、折扣在「銀行」的商品上

不合并版好康与限时活动仍是两处

玩家去哪找活动免费活动在右下「限時活動」（遊戲活動｜平台活動），付费活动在左下「銀行」，公告在右上菜单「公告訊息」
入口数量大厅 3 个窗口入口：左下「銀行」、右下「限時活動」、右上菜单「公告訊息」；底栏另有重点活动常驻入口
储值类活动在哪「銀行」最上方的「儲值活動」页签；礼包、折扣在「銀行」的商品上

两版都画了三项竞品借鉴的做法，设计稿和需求文档里还没有，留给你取舍

做法参考和现有文档的关系
底栏放重点活动常驻入口，图标上标剩余天数豪神底栏「歡樂券 22天」设计稿写的是底栏原银行按钮空出的位置由银行改版定，没有这一项
每个页签第一项放当期总览，只列本类活动豪神「豪神嘉年華」设计稿只有庆典专题页（第二批），没规定放在页签第一项
活动窗口右上「今日不再顯示」星城「活動快訊」只有窗口整个自动打开时才有用，涉及 10/13 弹窗方案（活动类按单项弹），文档没有

选哪一版，就是「储值类活动放银行还是放活动窗口」这个问主管的问题：合并版放活动窗口（「好康」页签），不合并版放银行（「儲值活動」页签）。

大厅

  1. ①参考 豪神 大厅底栏：重点活动常驻入口，图标上标剩余天数（「歡樂券 22天」）
  2. ②参考 豪神 大厅：活动入口只设一个，窗口内分页签；右下「活動中心」
  3. ③参考 豪神 大厅顶栏：另有常驻入口带倒计时；我方已有顶栏「首儲 336%」
  4. ④公告入口：右上菜单「公告訊息」

活動中心 · 遊戲活動

  1. ①参考 豪神 最新活動：顶部文字页签，页签带红点；分页思路参考豪神「特別活動｜消費活動」，页签名按我方需求
  2. ②参考 豪神 / 金好运 / 星城 活动列表：角标（熱、新）＋名称＋红点；剩余天数为我方新增
  3. ③参考 豪神 嘉年華：第一项放当期总览，此页签的总览格只放游戏活动
  4. ④参考 豪神 嘉年華：右侧总览格，每格名称加起止日期

活動中心 · 平台活動

  1. ①参考 豪神 最新活動：顶部文字页签，页签带红点
  2. ②参考 豪神 / 金好运 / 星城 活动列表：角标（熱、新）＋名称＋红点；剩余天数为我方新增
  3. ③参考 豪神 嘉年華：每个页签的第一项放当期总览，此页签的总览格只放平台活动
  4. ④参考 豪神 嘉年華：右侧总览格，每格名称加起止日期

活動中心 · 好康

  1. ①参考 豪神 消費活動：付费活动单列一个页签，页签名按我方需求为「好康」
  2. ②参考 豪神 新手助力包：右侧直接放活动页（工具版式页）
  3. ③参考 星城 星城回饋卡：「前往商城」按钮，此处为「前往銀行」
  4. ④参考 豪神：每个页签默认选中第一项

銀行

  1. ①参考 星城 商城「優惠專區」：商品卡斜角标，此处为「加赠 X%」
  2. ②参考 星城 商城「優惠專區」：指定礼包的专属角标，此处为「满 X 送 Y」
  3. ③参考 星城：付款动作集中在商城，窗口只有商品页签

公告

公告仍从右上菜单进，与不合并版相同

  1. ①参考 豪神 最新活動：顶部文字页签；红点表示该页签有未读
  2. ②参考 星城 官網公告：一行一条，日期＋标题；星城行首的分类标签，此处由页签表示
  3. ③参考 金好运 公告（喇叭页签）：右侧直接显示正文，不放主视觉大图
  4. ④只有「活動」页签的公告，正文下有「前往活動」按钮
