## 五、已定的设计（现有文档都按这些写；唯一依据是 `资料/方案设计稿.md`）

- **一个活动 = 工具 + 参数 + 素材 + 投放。** 运营在后台选工具、填参数（时间、对象、门槛档位、奖励、上限），选版式和对象，审核后排程上架。玩法逻辑只开发一次。
- **工具七个**：礼包、累充、满减、折扣、抽奖、团购、一元夺宝。分档：必需是通用设置、复制、审核、数据页、三个入口、礼包、累充、满减、折扣；尽量是抽奖、庆典专题页、现有玩法后台接入、曝光位自动生成、循环时段、预估成本与测试账号预览；可选是团购、一元夺宝（一元夺宝要法务先确认）。
- **满减、折扣都做成多送**：App 内购价格档固定，不能直接减价。满减是单笔满额加赠；折扣是同价加赠，用「加赠 X%」角标。
- **礼包新增「分日领取」**：买一次，分 2–30 天领，当天不领作废，比如回馈卡、7 日礼。
- **归属规则**（系统自动判断，运营不手选）：必须先储值或购买才能参与的进银行。三种情况不算：只把「本期储值过」当参与资格的押注、登入活动；活动内可选的付费道具；但「买一次、之后每天领」算进银行。剩下的活动，指定了游戏的进限时活动 · 游戏活动，其余进平台活动。
- **银行**：移到左下原好康位置，六个页签不变，最上方加「储值活动」，只放累充、满减、团购、付费抽奖、一元夺宝。礼包留在原页签：每日刷新、多选一固定在线上购点；全服限量固定在优惠礼包·平台限量；单包、分日领取由运营在线上购点、专属礼包、卡别限购、超值礼包里选（10/28 同步）。
- **限时活动**：用竞品通行的活动窗口。顶部「游戏活动｜平台活动」两个页签；左侧列表每项是角标（可无）、名称、剩余天数、红点；右侧大图加活动期间加「立即前往」；复用现在好康面板的组件。
- **公告**：从右上菜单进。顶部「官方｜活动｜其他」三个页签，每页只列本类；列表每行是日期加标题，未读有红点；右侧是正文阅读区，不放大图；只有活动类公告有「前往活动」按钮。自动生成的活动公告不带图。
- **曝光位**：Banner、弹窗、推播（发到玩家手机通知栏的消息）、公告活动类、游戏内悬浮按钮，只做引流，点了都跳主入口。
- **10/28 补充（Dk 认可）**：同一笔多种优惠，首储 → 生涯限购 → 折扣取一个，再和满减比、给加赠多的，累充照算，同工具活动重叠时提交审核提示冲突；储值归因是订单用到哪个活动的礼包或加赠就算哪个，一笔可计入多个活动；「大厅限时活动入口」后台加「所在页签」「右侧大图」（必需）；储优回馈、限时加码在折扣上线后停止新建；保留顺序 = 通用设置 → 礼包 → 商城（含储值活动页签）→ 累充 → 满减 → 限时活动与公告 → 折扣；到成本上限的最后一笔照发，结束后领奖截止内可领，分日领取领完为止，两页签都有红点开平台活动，退款沿用现有处理。
