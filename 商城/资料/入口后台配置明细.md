# 盘点A：大厅三入口（好康活動 / 限時活動 / 公告）后台配置能力与客户端显示规则

盘点日期：2026-10-27　范围：只读检索 Jira（RICH）与 Confluence（JD），未写入任何内容。
读不到的东西：所有页面和工单里的后台截图、附件（blob 图），所以"下拉里到底有哪些选项"这类只能靠文字和 BUG 单反推。

## 0. 先看结论

1. **三个入口是三套互不相通的后台**：好康 = 活動管理 → 好康設置 → 活動列表；限時活動 = 活動管理 → 大廳限時活動入口；公告 = 公告管理（热门资讯 / 系统公告等）。同一个活动要上三个入口，就要在三个后台各配一次。
2. **三套的标签词表各不相同**：好康 5 个（精選/儲值/好康/最新/熱門）、限時活動 6 个角标（押注/儲值/登入/分享/回歸/其他）、公告（精選/儲值/好康 + 游戏类型转輪/柏青…）。RICH-17149 计划把好康的词表改成限时活动那 6 个，**该单仍是待办**。
3. **没有"游戏活动 / 平台活动"分类字段**（限时活动），**也没有"官方 / 活动 / 其他"分类**（公告）。这两个分类是新需求，要开发（推断，依据见各表）。
4. **"新活动要出现在入口"不是自助配置**：每次新增活动类型，都要开发把它加进"连结位置"下拉。至少 4 张已完成的工单为证（BUG 单 RICH-19709 / 22592 / 20217；需求单 RICH-20355 的起因也是排行榜选了却保存不了）。
5. **好康单活动主页的统一架构（RICH-17149）还没做完**：客端、美术、营运三张子单全是待办；Web 实作的"百家連勝獎"在好康里缺时间和前往按钮，转需求待办（RICH-24945）。
6. **你问的弹层（左 最新活動 / 公告訊息，右列表带 儲值 / 柏青 / 轉輪 标签）**：我判断是右上汉堡菜单「公告訊息」打开的，页签对应后台 公告管理 的 熱門資訊 / 系統公告。没有任何文档直接写明，见第 4 节。
7. 好康"改成金流/商城入口载体"：现有 4 种类型里没有商城/金流类；宣传图连结理论上能跳转，但下拉里有没有银行/商城页，没查到（见第 5 节）。
