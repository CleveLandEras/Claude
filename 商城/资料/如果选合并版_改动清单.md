# 如果选合并版：要改的地方（未动现有文档）

> 现有设计稿、需求评审材料、需求文档写的都是不合并版。Dk 选定合并版后按本清单改；工具本身（礼包、累充、满减、折扣、抽奖、团购、一元夺宝）的规则、通用设置、分批都不变，只改「储值类活动显示在哪个窗口」。
> 合并版的样子见 `../2026-10-27_两版原型对比.html` 合并版部分。

## 一处核心变化

| | 不合并版（现文档） | 合并版 |
|---|---|---|
| 储值类活动（累充、满减、团购、付费抽奖、一元夺宝） | 银行最上方「储值活动」页签 | 右下「活动中心」的「好康」页签，右侧有「前往银行」 |
| 右下入口 | 「限时活动」：游戏活动｜平台活动 | 「活动中心」：游戏活动｜平台活动｜好康 |
| 银行 | 七个页签（储值活动＋现有六个） | 现有六个页签，只卖商品；礼包、折扣、满减角标仍在商品上 |
| 公告 | 右上菜单，官方｜活动｜其他 | 不变 |
