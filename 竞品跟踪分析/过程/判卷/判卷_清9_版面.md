# 判卷 · 清9 · 版面评审

材料：1440 宽整页渲染切成的 8 段截图（段_01 至 段_08），按截图原尺寸查看，局部放大核对。读者：产品经理，只用电脑宽屏。附录默认折叠是有意设计，不算问题。

## 结论

**整体读起来清楚、不挤，层级明确。没有会让读者看不懂或读错的严重问题。** 问题集中在三处：首屏的"有几块、哪几块最要紧"对不上；三栏排的细节截图太小，图里的证据看不清；竞品顺序和计数口径前后不一致。

| 严重程度 | 条数 |
|---|---|
| 严重（看不懂或读错） | 0 |
| 中等（看着吃力） | 4 |
| 轻微 | 5 |

截图看不看得清：两栏大图（第二、三章的 545px 宽图）看得清；三栏图（约 357px 宽）只能看清大标题，表单字段和规则小字看不清；第一章时间线缩略图（约 155px 宽）只能用来认出是哪一张。

---

## 一、第一印象

**眼睛先落在哪：** 顺序是标题"竞品跟踪：金好运、星城、豪神娱乐城"，然后是蓝色左边框的"核心结论"大字，再到编号 1–5 的卡片。这个顺序是对的。

**能不能一眼看出讲什么、一共几块：** 讲什么能看出来，一共几块要自己对。

- 左侧目录列出结论、一至七章、附录 A–D，整体结构一眼可见。
- 但首屏同时出现三个数字：核心结论说"最直接的参照有**三处**"，下方是**五张**同等权重的卡片，第七章标题又写"短期两项……其余五项"，一共**七项**建议。读者要自己对出"三处"是卡片 1、2、4，也看不出哪几张卡片是马上能用的短期项（见问题 M1）。

## 二、可用性

读者要的信息（发现了什么、和我们有什么关系、下一步定什么）都拿得到：首屏卡片有"对我们"栏和"看第 X 章 ›"链接，每章末尾都有"我们现在 | 建议"框，第七章有汇总表。干扰很少，来源标注（如"录屏2 t0003.5"）已经调成浅灰，不抢眼。

有两处会让读者多花力气：时间线的计数口径和正文对不上（M4），细节截图看不清（M2）。

## 三、视觉层级

阅读顺序清楚：章节眉标（蓝色小字"一 · 弹窗"）→ 结论式 H2 → 灰色导语 → 证据（截图、表格）→ "我们现在 | 建议"框。章与章之间留白约 100px，章内各块间距约 16px，分组明确。

不足：核心结论三行整段加粗、字号很大，三处参照埋在一个分号长句里，不好扫读；"短期 / 中期"这条最影响决策的区分，在首屏卡片上没有任何视觉标记（M1）。

## 四、一致性

做得好的地方：章节模板统一；图注格式统一（加粗竞品名＋说明＋浅灰来源）；表格样式统一（只有横线、行首加粗）；卡片圆角、阴影、间距统一。

问题：竞品顺序在表格之间来回换（M3）；颜色有一色多义（L3）；第七章的时间标签写法不统一（L4）。

## 五、可读性

- 正文对比度足够：导语和正文约 7:1（按截图像素估算，下同），字号约 14–15px，导语行长约 56 字，读起来舒服。
- 浅色文字都用在该弱化的地方：来源标注约 2.3:1，表格里的"录屏中未出现"约 2.5:1。这样处理让"没看到"和"有数据"一眼就能区分开，是对的。
- 没有发现标点出现在行首。
- 有几处数字和单位被拆到两行，还有几处单字落到下一行（L1）。

## 问题清单

### 中等

**M1. 首屏的数量对不上，也看不出哪些是短期可用**（第一印象 / 层级）
- 位置：段_01 核心结论框和 1–5 号卡片；段_07 第七章标题和表格。
- 现象：核心结论说参照有"三处"，下面是 5 张同等权重的卡片，没有标出是哪三张。卡片"对我们"栏也没标短期 / 中期。"短期两项可直接放进现有方案"这个最关键的决策信息，要滚到页面底部第七章才看到。核心结论三行整段粗体，三处参照挤在一个长句里。
- 影响：产品经理看完首屏不能马上回答"哪些现在就能用"，要自己对 3、5、7 三个数字。

**M2. 细节型截图按三栏排太小，图里的证据看不清**（可读性 / 截图）
- 位置：段_05 第四章三图（金好运赠礼页、星城金庫&兌換、豪神保险箱）；段_02 第一章三张汇总窗口图；段_06 星城"每日必買"。
- 现象：图约 357px 宽，图注写的"最低数量、服务金、送礼密码、冻结明细""50級以上才可以使用……"等内容，在图里放大到 2 倍才勉强认得出。金好运赠礼页左半张是空的"無資料"面板，占了一半面积。第一章时间线缩略图约 155px 宽，图里文字完全看不清，只能认出是哪一张。
- 影响：读者无法用图核对说明文字，证据只能靠信。从静态截图看不出正文图能不能点击放大；附录 B 写了"点图放大"，正文图如果不能放大，这个问题会更明显。

**M3. 竞品顺序在表格之间不一致**（一致性）
- 位置：段_05 第四章表格的列顺序是 金好运 / 星城 / 豪神；紧接着第五章商城对比表（段_05 底部至段_06）的列顺序是 星城 / 豪神 / 金好运，配图也按这个顺序；段_03 第一章"同一内容既在窗口里、又单独出现"表的行顺序是 星城 / 豪神 / 金好运。标题、概况条和第一章时间线都是 金好运 / 星城 / 豪神。
- 影响：连续两张对比表换了列序，读者要重新看表头，容易把一家的数值看到另一家头上。

**M4. 第一章时间线的"合计"和正文数字对不上**（可用性）
- 位置：段_02 时间线各竞品名下写"合计 2 个 / 3 个 / 8 个"；同章导语和首屏卡片 1 写"金好运 1 个、星城 2 个、豪神 7 个"。
- 现象：差的那 1 个，是灰字标注"开始时已开着"的窗口，但"合计"旁边没有说明。
- 影响：读者会怀疑数字写错，或者得读完图例再自己算一遍。

### 轻微

**L1. 数字和单位被拆到两行，有单字孤行**（可读性）
- 数字和单位拆开："抽出关键画面 130 / 张"（段_01 概况条）、"窗口第 1 / 项"（段_02）、"新增 6 个减为 4 / 个」。"（段_03）、"保留至少100 / 萬」"（段_05）。
- 单字孤行："不含登录过 / 程""游戏内画面没 / 拍到"（段_01 概况条）、"没有公告分 / 页"（段_02）。
- 原因：数字两边用的是普通空格，浏览器可以在空格处换行；概况条每格太窄，也更容易孤行。

**L2. "n/3 款"图例放在后面，而且太淡**（可读性 / 层级）
- 位置：段_01 底部、段_02 顶部，五张卡片下方灰底上的一行小字（约 12px，约 3.8:1）。
- 现象：读者先在卡片里看到"3/3 款"标签，后面才看到解释。同一行里还有"「录屏中未出现」不等于竞品没有"这条重要口径，很容易漏看。好在"3/3 款"的意思大体能猜出来，所以算轻微。

**L3. 颜色一色多义**（一致性）
- 蓝色既是全页强调色（结论边框、序号、链接、章节眉标、"n/3 款"标签），又是第一章的分类"汇总窗口"；"汇总窗口"标签和"n/3 款"标签样式完全一样。
- 绿色既用于"对我们 / 建议"标签，又是分类"免费领取"。
- 这些分类颜色只在第一章出现，而且有图例，所以影响小。

**L4. 第七章的时间标签不统一**（一致性）
- 位置：段_07"按我方项目归并"表。
- 现象："弹窗（短期）"两行、"标签（提案）"、"弹窗（中期）"各一行，其余三行没有标签。标题说"其余五项作为提案"，读者要自己判断"中期"和没标签的是不是都算提案。短期两项只靠括号文字区分，没有视觉区分。

**L5. 附录折叠卡片的展开提示太弱**（可用性）
- 位置：段_07–08。
- 现象：只有一个很小的浅灰"▸"，卡片看起来更像标题而不是可点的按钮。

## 做得好的地方

1. **结论先行**：标题 → 核心结论 → 编号发现卡片，每张卡片标题和对应章节 H2 一字不差，并带"看第 X 章 ›"链接，从摘要跳到正文很顺。
2. **概况条讲清边界**：竞品 / 样本 / 视角 / 不含四格，尤其"不含：收入、下载数据与效果"，让读者一开始就知道这份报告不回答什么。
3. **章节模板稳定**：眉标 → 结论式 H2 → 导语 → 证据 → "我们现在 | 建议"，读到第二章就知道后面每章怎么读。
4. **该弱化的都弱化了**：来源标注、"录屏中未出现"、"先要定的"都做了弱化，主次分明，又不影响阅读。
5. **宽屏不挤**：正文区约 1100px，导语限制在约 840px，章间留白充足，白卡片放在浅灰底上，分组清楚。
6. **两栏大图看得清**：第二、三章的两栏截图（豪神个人资料、好康資訊、7日優惠禮、星城回饋卡）图里的主要文字都能直接读出来。
7. **第一章时间线**按竞品分行、按出现顺序排列，加分类标签和"我方"对照行，结构一眼能看懂。

## 改进建议（按优先级）

1. **首屏标出"三处最要紧"和"短期 / 中期"。** 核心结论拆成三条短句，每条注明对应卡片编号（1、2、4），去掉整段粗体；五张卡片的"对我们"栏加上"短期可用 / 中期提案"小标签，写法和第七章统一（第七章表格也补齐标签）。（解决 M1、L4）
2. **固定竞品顺序，统一计数口径。** 所有表格和图组固定为 金好运 → 星城 → 豪神（和标题一致）；时间线"合计 N 个"改成和正文一致的写法，比如"共 2 个（录屏中弹出 1 个）"。（解决 M3、M4）
3. **细节截图按"要看清什么"来排。** 第四章三图、第一章汇总窗口三图、第五章星城"每日必買"改成两栏或通栏，或者只裁出图注提到的区域，并支持点击放大；把金好运赠礼页空白的左半边裁掉。（解决 M2）

顺手可修：数字和单位之间改用不换行空格（`&nbsp;`），消除 L1；"n/3 款"图例移到卡片上方，或放进核心结论框底部，同时加深颜色（L2）。

## 评审局限

- 只看了静态整页截图，以下几点无法判断：左侧目录是否固定在屏幕上、当前章节有没有高亮、正文图能不能点击放大、附录展开后的版面。
- 段与段的交界处有一行文字被切开，这是截图切片造成的，不是页面问题，没有计入。
- 对比度是按 JPEG 截图像素估算的近似值。
