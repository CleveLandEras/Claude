# 首屏与章节标题的本意（读者测试前写下，判卷时对照）

| 句子 | 本意 |
|---|---|
| 核心结论第一句 | 在三个新账号的录屏里，三款竞品都有一个把活动汇在一起的窗口；其中的重点内容另外还会单独弹出来；三款也都设计了让玩家每天回来的东西。这是录屏所见，不是竞品对所有玩家的规则。 |
| 核心结论第二句 | 对我们的项目，最能直接借鉴的有三个方面：弹窗方案里决定哪些内容单独弹、哪些放进汇总窗口；推送方面怎样让更多玩家留下游戏外联系方式；银行改版时转币、赠礼要设哪些限制。 |
| 结论1 标题 | 三款都有汇总活动的窗口；另外，窗口里的重点内容同时也单独弹出（这一点两款看到）。 |
| 结论1 对我们 | 我们 10/13 交的弹窗方案本来就是让各人群的首选内容单独弹，竞品也这样做，是旁证；把首选以外的活动放进一个汇总窗口，是可以以后再提的中期建议，不改现在方案。 |
| 结论2 标题 | 星城和豪神两款都提示玩家绑定手机或 LINE；但给奖励（送游戏币）的只有豪神。 |
| 结论2 对我们 | 建议把「绑定手机或 LINE 送币」作为新增玩家弹窗的一个候选内容，目的是让这些新玩家以后如果流失，还能通过短信、LINE 推送找回。 |
| 结论3 标题 | 三款都有让玩家每天回来的设计，但做法各不同；其中两款让玩家付一次钱、之后每天登录来领。 |
| 结论3 对我们 | 设计每日任务框架时，把三款的三种做法都当作候选；如果用固定时刻，这些时刻也正好是发推送的时机。 |
| 结论4 标题 | 三款对转币、赠礼都设了限制；但每款录屏只拍到其中一部分规则。 |
| 结论4 对我们 | 如果银行改版包括存取和赠礼，就按五类（门槛、费用、冷却、上限、凭证）整理规则来决定。 |
| 结论5 标题 | 三款商城各有一种加送（多给币）的做法；给新账号的低价、高加送礼包，只在豪神看到。 |
| 结论5 对我们 | 先算出我们两个新手入口（NT$49 通行证、NT$50 首储礼包）多给了多少，再决定商城要不要加类似商品。 |
| 第六章标题 | 除前五点外还有八个发现，可供中期项目参考，多数只在一两款里看到。 |
| 第七章标题 | 建议里有两项属于短期项目、可以直接放进现有方案；另外五项是提案。 |
