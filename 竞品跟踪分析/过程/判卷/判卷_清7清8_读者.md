# 读者测试：只凭首屏与章节标题作答

## 1. 核心结论和理由（我的复述）

- 作者用新号录了三款台湾老虎机社交游戏（金好运、星城、豪神），每款一段手机录屏，合计不到 6 分钟。看到的共同做法有三点：活动集中在一个汇总窗口里，重点活动再单独弹出来，并且设计了让玩家每天回来的机制。
- 作者认为对我方最有用的参照有三处：一是我方弹窗里哪些内容单独弹、哪些收进汇总窗口；二是借鉴“绑定手机/LINE”，让玩家流失后还能在游戏外被联系到；三是我方银行改版时，转币和赠礼要设哪些限制。
- 理由是三款竞品在这几方面都有可见做法（多数是 2/3 或 3/3 款）。我方 10/13 交的弹窗方案已与“首选单独弹”一致，其余建议分成短期两项、提案五项。
- 样本只有新号视角，时间短，看不到付款和游戏内画面，所以多处证据只来自一款，作者自己也标了“证据弱”。

## 3. 不确定的词、现状/计划分不清、前后矛盾

### 3.1 不确定指什么的词（可能的理解）

| 词 | 可能的理解 |
|---|---|
| 汇总窗口 | ① 登录后自动弹出的活动合集弹窗；② 大厅里点进去才看到的“活动中心”页面 |
| 单独弹 / 自动出现的窗口 | ① 登录时自动弹出的单个活动窗口；② 所有自动弹出的窗口，包括汇总窗口本身（金好运 1 个、星城 2 个、豪神 7 个，是否把汇总窗口算在内不明） |
| 重点内容 vs 首选内容 | ① 同一个意思；② “重点”指竞品认为重要的活动，“首选”是我方方案里的专用词（例如每个人群只弹一个最优先的内容） |
| 首选弹窗候选 | ① 争取成为“首选单独弹”的那一个弹窗；② 放进首选名单里的候选之一（可能有多个） |
| 新增人群 | ① 新注册/新安装的玩家；② 在我方弹窗方案里新加的一个人群分组；③ 尚未绑定手机/LINE 的玩家 |
| 推送 / 触达 | ① App 推送通知；② 短信、LINE 消息；③ 两者都算（核心结论说“推送”，结论2 说“短信、LINE”） |
| 银行改版 | ① 我方正在做的银行（保险箱）功能改版；② 竞品某款做过的改版（“若含”说明范围未定，倾向①） |
| 转币 vs 存取 | ① 玩家之间转币；② 把币存进/取出保险箱；③ 两者统称（核心结论说“转币”，结论4 说“存取”） |
| 每款只看到一部分 | ① 录屏太短，每款只拍到它规则的一部分；② 每款竞品本身只做了五类限制中的一部分 |
| 整理规则 | ① 把竞品规则按五类归档对照；② 按五类设计我方自己的规则 |
| 兑换单向 | ① 只能把币兑换进保险箱、不能换回；② 只能某种币换另一种，不能反向（对象不明） |
| 120% 超優惠 | ① 加送 120%；② 总价值是原价的 120%（即加送 20%）；③ 只是宣传语，不是实际比例 |
| 万元档官网包 | ① 约 NT$10,000 的礼包，在官网（游戏外）购买；② 1 万游戏币档的礼包 |
| 两个新手入口（NT$49、NT$50） | ① 两个不同的新手礼包；② 同一礼包在不同平台/渠道的价格；③ 游戏里两个不同位置的购买入口 |
| 同类商品 | ① 豪神式新手低价高加送包；② 星城式每日/每周限购包；③ 泛指加送类商品 |
| 中期提案 / 中期项目 | ① 另有一个已立项的中期项目；② 只是“以后再做”的意思 |
| 像新号 | ① 账号不是作者建的，只能推测是新号；② 是新号，但不确定有没有被动过 |
| 证据弱 | ① 只有一款看到；② 只看到一个画面；③ 新号视角下可能看不全 |

### 3.2 读不出是现状还是计划

- **10/13 呈交的弹窗方案**：已提交，但不知道是否已获批、是否已上线。
- **每日任务框架**：是已有的框架，还是正在设计中？“列为候选”是已经列了还是建议去列？
- **银行改版**：在做还是在计划？“若含存取与赠礼”说明范围还没定。
- **我方 NT$49、NT$50 新手入口**：入口本身像是现状，但加送比例“先算”，说明还没算过。
- **绑定送币作为首选弹窗候选**：是建议，还是已经要加进方案？是否属于“短期两项”之一？
- **我方是否已有绑定手机/LINE 功能、短信/LINE 推送渠道**：没说。
- **章节七的“可直接放进”**：是建议放进，还是已经放进了？

### 3.3 看起来前后矛盾的地方

1. **单独弹是 3 款还是 2 款**：核心结论和结论1 标题写“三款都……还单独弹”，依据是“2/3 款重点内容再单独弹”。金好运只自动出现 1 个窗口，似乎就是没单独弹的那款。
2. **“三处参照”与“短期两项”对不上**：核心结论说最直接的参照有三处，章节七说短期能直接放进方案的只有两项；而且结论1 的“收进一个窗口”又被标成中期提案。
3. **推送与短信/LINE**：核心结论说“推送触达”，结论2 的落点是“短信、LINE 触达”，两者不一定是同一回事。
4. **转币与存取**：核心结论说“转币与赠礼”，结论4 的“对我们”写“存取与赠礼”；依据大多讲保险箱（星城“保险箱里的币不能押注”并不是转币或赠礼的限制）。
5. **五类规则与证据**：五类里的“冷却”在依据中找不到对应的竞品例子。
6. **“各用一种”与“只看到”**：结论5 断言三款“各用一种”加送方式，但首屏注释说“录屏中未出现不等于没有”，金好运也只是“只看到”一个包。
7. **建议条数**：结论1–5 的“对我们”能数出约 7 条（含“与方案一致”这条印证），章节七合计也是 7 项（2+5）；但章节六还有“八处”中期参照，它们是否算进“其余五项”不清楚。
8. **“首选单独弹”与豪神 7 个自动窗口**：作者说竞品与我方“首选单独弹”一致，但豪神一次弹 7 个，不像只弹首选，“一致”的说法存疑。
9. **新号的确定程度**：标题和核心结论直接说“新号”，范围里却写“都像新号”。

## 4. 最想问作者的 5 个问题

1. 章节七里“短期两项”具体是哪两项、要放进哪份“现有方案”？其余五项是什么？跟核心结论的“三处参照”怎么对应？
2. 重点内容单独弹到底是三款还是两款？金好运那 1 个自动窗口是汇总窗口还是单独弹？
3. 10/13 弹窗方案、每日任务框架、银行改版、NT$49/50 新手入口，现在各自处于什么状态（已上线／已提交待批／计划中）？银行改版是否包含存取和赠礼？
4. “新增人群”“首选”“推送”分别指什么？我方现在是否已有绑定手机/LINE 的功能和短信/LINE 的发送渠道？绑定送币要送多少，是否已估算成本？
5. 样本只有 346 秒、账号只是“像”新号，哪些结论足够支撑决定，哪些要先补录（附录里的“下次怎么录”）？这份报告需要读者现在拍板什么？
