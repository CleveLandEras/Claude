# 观察任务说明（给逐款观察员）

## 你的任务
你负责一款竞品的一段手机录屏。逐张看关键帧，把**屏幕上看得到的东西**记成观察记录。你只做观察，不做分析、不给建议。后面会有独立核对员拿你的记录逐条对照截图，数字或原文错一处就退回。

## 材料
- 关键帧（去重后的画面，文件名是录屏里的秒数）：`/Users/decheng.huang/claude/竞品跟踪分析/素材/关键帧/录屏N/tXXXX.X.jpg`，宽 1600。
- 每秒一帧的完整序列（用来补关键帧漏掉的画面、确认先后顺序）：`/Users/decheng.huang/claude/竞品跟踪分析/素材/每秒帧/录屏N/tXXXX.X.jpg`，宽 1170。
- 原视频：`/Users/decheng.huang/claude/竞品跟踪分析/<视频文件名>`，2340×1080。
- 看不清小字或价格时，用原分辨率裁剪放大：
  `/Users/decheng.huang/claude/竞品跟踪分析/_工具/grab <视频路径> <秒> <输出.jpg> [x y w h]`（坐标按 2340×1080 原图像素），输出放到 `/Users/decheng.huang/claude/竞品跟踪分析/过程/裁剪/`，文件名以 `录屏N_` 开头。

## 规则
1. **只写看到的。** 推断一律写成「推断：……（依据：……）」，和观察分开。不确定的写「看不清」，不猜。
2. **每条记录带帧号**（如 `录屏3 t0021.5`），能让核对员直接打开那张图核对。
3. **原文照录**：屏幕上的关键文字保留繁体原文，放在「」里；数字、价格、日期、倒计时、百分比一字不差。
4. **不记录其他玩家的昵称**（排行榜、播报里的玩家名写「玩家昵称（略）」）；录屏账号自己的昵称也只写前两个字。
5. **录屏者的操作**（点了关闭、点了某个分页、在等加载）根据前后帧判断，写「操作：……（据 tA→tB）」。
6. 每一张关键帧都要有对应记录；连续几张是同一画面的小变化，可以合并成一条并列出全部帧号。
7. 发现关键帧之间漏了画面（在每秒帧里出现、关键帧里没有），补记并注明来自每秒帧。每秒帧也没拍到、只闪过不到 1 秒的画面，用 grab 从原视频抓，帧号写「原视频 tX.X」，裁剪文件名写在该条记录里（如 `录屏N_full_t4.6.jpg`）。
7.5 **操作的依据**：录屏开着触控显示，画面上会出现点击圈。看到点击圈的写「据 tX 点击圈在……」；没看到点击圈、只能从前后画面推出来的，写成推断。
7.6 **同一项的加载帧和出图帧合成一条**（如先转圈 Loading、再出图），列出两个帧号。
7.7 聊天内容可以记，发言人昵称写「（略）」。
8. **不写「没有某功能」**：录屏只拍到一部分，只能写「录屏中未出现」。
9. 每条记录末尾标把握：清楚／部分看不清（写明哪部分）。

## 样例（格式参照，内容是虚构的）
```
#### 录屏9 t0012.5、t0013.0｜登录弹窗：每日首储礼
- 画面类型：登录弹窗
- 原文：「每日首儲禮」「首儲送 300%」「今日不再顯示」
- 数字：价格「NT$30」；赠送「300%」；倒计时「23:59:41」
- 操作：点右上 X 关闭（据 t0013.0→t0014.5，下一帧为另一弹窗）
- 推断：像是新账号专属（依据：标题含「新手」，账号 Lv.1）
- 把握：清楚
```

## 输出
写到 `/Users/decheng.huang/claude/竞品跟踪分析/过程/观察记录_录屏N.md`，结构如下：

### 一、身份与账号状态
- 游戏名（屏幕上出现的写法及帧号）、开发或品牌线索（帧号）。
- 录屏账号状态：等级、币值、VIP 或卡别、是否像新账号（只写看到的线索）。
- 录屏起止：从哪个画面开始（冷启动、已在大厅……）、到哪结束。

### 二、逐帧记录（按时间顺序）
每条格式：
```
#### 录屏N t0000.0（可并列多帧）｜画面名称
- 画面类型：登录弹窗／公告或活动中心／活动详情页／商城／储值渠道／大厅／功能页／账号绑定／系统提示／加载中／游戏外
- 原文：「……」「……」
- 数字：价格、数量、倍数、期限、倒计时（逐项）
- 操作：……（据 tA→tB）
- 看不清：……（没有就不写）
```

### 三、按主题整理（只从第二部分汇总，不新增内容）
1. **登录后的弹窗序列**：先写录屏是不是从冷启动或登录画面开始；不是的话写明「录屏开始前的弹窗看不到」。表格列「顺序｜帧号｜名称｜类型（付费礼包／活动宣传／免费领取／账号绑定／公告或提示）｜关闭方式（右上 X、按钮、今日不再顯示……）｜录屏者的处理」。
   - 算进序列的：没有点击圈就出现的窗口（自动弹出）。带分页的容器窗口（如活动中心）算一个，里面的项目记到第 2 节活动清单。
   - 气泡、跑马灯这类不挡操作的提示单列在表下，不算弹窗。
   - 录屏者自己点开的不算，单列。
2. **活动清单**：名称｜所在位置（哪个中心、哪个分页）｜类型｜期限｜奖励（原文）｜帧号。
3. **商城与储值**：分页名称；每个礼包或档位：名称｜价格｜内容（主币数量与加赠分开写）｜标注（加送%、限购、倒计时）｜帧号；储值渠道清单。弹窗里卖的礼包也列进来，注明出现在哪个弹窗。
4. **福利与留存**：签到、月历、每日领取、新手礼、回流、破产救济等。
5. **大厅**：入口清单（顶栏、侧栏、底栏，各写原文）、跑马灯或播报原文、彩金显示、游戏列表与标签（新機、熱門……）。
6. **社交与排行**：排行榜（名称、维度、刷新规则原文）、公会、聊天、赠礼。
7. **经济系统**：银行、保险箱、金库、兑换、序号兑换、背包、合成等，写字段和规则原文。
8. **账号与安全**：绑定手机、LINE、Facebook 的提示和奖励原文。
9. **录屏没覆盖或看不清的部分**。

完成后只回复：输出文件路径、记录条数、看不清的条数、你认为最值得核对的 5 处、这份说明里让你拿不准怎么写的地方。
