## 三个录屏原件怎么还原（11/04 搬家加）
三个录屏原件（231M、214M、121M）超过 GitHub 单文件 100M 的上限，仓库里放的是切开的分片（每片 49 MiB，不压缩、不丢画质），在 `录屏分片/`。从 GitHub 克隆之后，在仓库里跑：

```
bash 竞品跟踪分析/录屏分片/还原.sh
```

它把分片按顺序拼回 `竞品跟踪分析/Screen_Recording_*.mp4`，并逐个和 `录屏分片/分片sha256.txt` 里记的原件 sha256 比对，不符就报错、不留半成品。原件已被 `.gitignore` 挡住，不会被再次提交。手工还原：`cat 录屏分片/<原名>.part-* > <原名>`，再 `shasum -a 256 <原名>` 和 `分片sha256.txt` 里「原件:」那行比。
