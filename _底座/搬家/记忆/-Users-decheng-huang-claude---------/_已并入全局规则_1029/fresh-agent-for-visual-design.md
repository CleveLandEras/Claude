When design work has been rejected several times and my revisions are converging on my own framing, Dk suggested stopping iteration in my long context and giving a fresh agent the raw materials without my ideas or diagnoses (「无上下文污染」).

**Why:** Dk 2026-10-10 after three rejected versions of a deck's conclusion page (the last designed by me): 「这种设计我建议你单开无上下文污染的AGENT直接设计，效果可能比你反复思考好的多」. Scope of Dk's words: a suggestion, about design that keeps failing to pass.

**How to apply:** My default practice (not Dk's rule; adjust per case): package materials in a folder (e.g. `分析/设计参考_<名称>/`: 内容.md、读者原话.md、被退回*.png、参考/) — content/facts, Dk's standard, references Dk approves, rejected versions with Dk's verbatim reactions; ask the agent for several genuinely different options, a self-review, then polish one. Extending this to repeated wording failures is my inference. Related: [[stage-progression]], [[writing-and-layout]].
