---
name: dont-ask-about-presentation-format
description: 用户不愿被问「用什么格式/版面呈现」，要求我按可读性自行决定
metadata:
  type: feedback
---

问交付物格式（Markdown / HTML / artifact / 版面样式）时，用户回答：「这个格式不应该我来决定，目标是可读性易读性。」

**Why:** 格式属于执行判断，不是需求决策。把它抛回给用户等于让他替我做我该做的判断，还多一轮往返。他要的是结果的可读性，不是参与选型。

**How to apply:** 涉及呈现形式的选择直接定，按可读性择优，最多用一句话说明选它的理由。仍然该问的是会改变工作内容的事——交付范围、用哪份材料、要不要落地。参见 [[conclusion-first-report-form]]。
