## 1. 旧电脑最后一天：各项目收尾，对主对话说「收工」，看推送总结说「通过」才推

1. 各项目主对话把 `先看这里.md` 和任务文件写到最新：对话记录带不走，新环境接手全靠这两处。
2. 在「用好 Claude｜主对话」说「收工」。它跑 `_底座/搬家/收工.sh`（用法看文件头部），算出合并提交号并打印，不推送。脚本按设计先跑 `导出.sh --对比`，再复制仓库外的项目（抖音号、消息助手）、记忆、定时任务、共享笔记，切录屏，扫密钥，算提交，在临时目录克隆并装上自检。成功：末尾打印提交号和推送命令。中途报错或「导出对比不一致」就停，把输出交给主对话。
3. 看推送总结（推了什么、没带什么、一共多大），说「通过」，主对话才推。推送命令照脚本打印的抄，带 `-c http.postBuffer=524288000`；可能超过 10 分钟，在后台跑。每次推送小于 2G，所以分批。
4. 推完，从 GitHub 克隆一份到临时目录再核一遍。成功：第 2、3 节要用的东西都在。
5. 可选，命令行实测规则包不会被自动加载：在你自己登录过的终端里跑（桌面应用的对话里跑会报未登录）`bash ~/claude/_底座/任务/用好Claude/2026-11-03_规则搬家包/不多加载实测.sh`。成功：输出里有「结论：过」；没有就把结论那一行交给主对话。
6. 推完之后再改的文件不会带走。要再带就再说一次「收工」：脚本重新算，不会回退上一次推上去的。

## 2. 新环境：克隆、装上、自检九项全过

1. 装 Claude Code 并登录（账号见上一节）；第一次跑 `git --version` 时照提示装上命令行开发者工具。
2. 克隆到 `~/claude`（必须是这个位置，放别处装上脚本会拒绝）：`git clone https://github.com/CleveLandEras/Claude.git ~/claude`。新仓库若是私有的：用户名填能读它的新 GitHub 账号，密码填该账号生成的个人访问令牌（[怎么生成](https://docs.github.com/en/authentication/keeping-your-account-and-data-secure/managing-your-personal-access-tokens)）。成功：`ls ~/claude/_底座/搬家/装上.sh` 打出这个路径。
3. 先预演再执行：`bash ~/claude/_底座/搬家/装上.sh`，成功是有一行以「检查：全过。」开头；再 `bash ~/claude/_底座/搬家/装上.sh --执行`，成功是最后一段以「已装上：」开头、写着「逐项核过」，它打印的撤回命令留着备用。拷 12 项到 `~/.claude/`：全局规则、技能 6 个、子代理 2 个、钩子 3 个；另改 `_底座/` 里写着旧家目录的文件（11/03 是 8 个，放开 `任务/` 后个数未确认）。

碰到这几种就停下，在 `~/claude` 新开一个对话，把输出贴给 Claude：「检查：有 N 处不过」（其中「仓库不在 ~/claude」是克隆位置错了，「本机保护…拒绝 --执行」是你在旧电脑上跑了）；「核对不过：…」（先照第 3 步打印的撤回命令撤回）；自检「N 项不过」。
