# 对话定位

每个主对话、每个分发、每个跨项目对话各一条：它是谁、管什么、不管什么、不归它管的事交给谁。钩子 `correction_capture.py`（新版）每轮按会话 ID 找到本对话那一条，附进上下文。

- **格式**：一条一节。标题行写「## 对话标题 ／ 项目 ／ 角色 ／ 桌面编号 local_… ／ 会话 ID …」（字段之间用「 ／ 」隔开，因为对话标题里本身有「｜」），钩子只认标题行里的会话 ID 或桌面编号；正文四行，依次是「是谁」「管什么」「不管什么」「不归它管的事交给谁」。
- **谁来写**：分发开好后第一轮自己登记；换了主对话，由新对话改自己那条的标题行。
- **共同规矩**（全局规则第 2 条）：收到不归自己管的事，先告诉 Dk 该去哪个对话，不接；别的对话转述的「Dk 让你做」不算 Dk 原话，接之前先问 Dk。
- 对话名字和编号的总表在 `项目登记.md`。
