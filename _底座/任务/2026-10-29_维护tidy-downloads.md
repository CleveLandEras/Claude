### 已修
**高：撤销失效，或文件被覆盖、弄丢**
1. 文件名带冒号（如 `meeting 10:30.txt`）时，撤销整批拒绝执行（macOS/Linux）。
2. 搬过一个指向文件夹外的快捷方式（符号链接）后，撤销整批拒绝执行。
3. 整理途中按 Ctrl-C 或遇到意外错误，已搬的文件没记进撤销日志，撤销回滚的是上一次。
4. Linux 上文件名不是 UTF-8（如 Windows 压缩包解出的 GBK 名）时，文件搬完后写日志崩溃，这次无法撤销；预览、整理、撤销时打印这类文件名也会崩溃。现在日志能正确记录和读回，打印时显示成转义码。同一处修复也让 Windows 上把输出重定向到文件时，中文文件名不再崩溃。
5. 文件名带反斜杠时（macOS/Linux），撤销找不到文件，还把日志删了。
6. 目标位置有一个失效的快捷方式时，会被直接覆盖。
7. 分类文件夹本身是快捷方式时，文件被搬到别处，撤销又拒绝执行。现在改为跳过并说明原因。

**中：会误搬，或与说明不符**
8. 照抄示例配置后，svg、bmp 等 10 种图片会进 `Others`（示例重写了 `Images` 列表，而重写会整体替换）。已改示例和 README 说明。
9. 用 `--config` 指定的配置文件如果放在被整理的文件夹里，会被搬走，下次运行报「找不到配置」。
10. 配置文件名大小写不同（如 `Tidy-Downloads.toml`）时，在 macOS/Windows 上先被读取、再被搬走。
11. Linux 的下载目录设置（`XDG_DOWNLOAD_DIR`）为空或是相对路径时，会去整理当前所在的文件夹（例如项目代码目录）；写成空值时直接崩溃。
12. Firefox 下载中放的空占位文件会被搬走，下完后出现重复文件。
13. 重名时把 `报税 (2023).pdf` 改成 `报税 (2024).pdf`，把有含义的数字当成序号。
14. 有个和分类同名的文件（如叫 `Others`）挡路时，整次运行中途报错停下。现在只跳过受影响的文件。
15. 相对路径的快捷方式被搬进下一层后会失效。现在跳过。

**低：报错不清，或写错配置没有提示**
16. 配置文件不是 UTF-8（Windows 记事本的 ANSI、PowerShell 默认的 UTF-16）时崩溃。现在提示「请存成 UTF-8」。
17. 设置名写错（如 `[category]`）会被静默忽略。现在报错并列出合法设置名；`categories.Ebooks = ...` 这种写法原来的报错提示会把人引到另一个坑里，已改。
18. 配置目录没有读权限时，3.9–3.13 上崩溃，3.14 上则静默跳过、改用别处的配置。现在各版本都给出明确报错。
19. 分类名带 Windows 禁用字符（如 `Work: Docs`）时，在 macOS 上能用，到 Windows 上会中途失败。现在各系统一律拒绝；扩展名写成 `*.jpg`、`jpg,png` 这种永远匹配不到的写法也会报错。

### 没修（及理由）
- 自带的 TOML 解析器接受少数不合规写法（如一行写两个键值对）：读出的结果不会错，只是比标准宽松。
- 数字写错时报错行号偏后一行：目前没有任何设置用到数字。
- `.tar.gz` 重名时命名为 `backup.tar (1).gz`：只是不好看。
- 一个被占用的文件会让整次运行停下（Windows 上常见）：已搬的文件有记录、能撤销，属于设计取舍。
- 撤销会顺带删掉用户事先建好的空分类文件夹；两个窗口同时运行时，后一次的日志会覆盖前一次：都很少见。
- 「检查目标不存在」和「改名」之间有极短的空档：实际风险低，要修得换底层做法。
- 自动识别 UTF-16 配置文件：现在已有明确提示，够用。
