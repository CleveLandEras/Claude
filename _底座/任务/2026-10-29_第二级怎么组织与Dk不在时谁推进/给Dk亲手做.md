## 一、新钩子（第 5 件）：已装好

10/29 18:06 你已在终端换上新版，旧版备份在 `~/.claude/backups/correction_capture_1029旧.py`。

**换了以后有什么不同**：
- 每条消息（包括你的消息、夜里定时叫醒、子代理回报、别的对话发来的消息）都会附上 `~/.claude/CLAUDE.md` 的全文，还有这个对话在 `~/claude/_底座/对话定位.md` 里的那一条。
- 规则改了以后，已经开着的对话下一条消息就能用上新版。
- 原来的纠正提示照旧，一字没改，仍然只对你本人的消息生效。
- 代价：每条消息多约 4,600 个字符（约 4,000 token），压缩会更频繁。

**核对装上了没有**：打开终端（Mac 自带的「终端」，或 Claude 应用里的终端面板），粘贴下面这一行，回车。

```
diff -q ~/claude/_底座/设置/correction_capture_新.py ~/.claude/hooks/correction_capture.py && ls ~/.claude/backups/correction_capture_1029旧.py && echo '{"session_id":"7cc8aeda-78fa-4164-bf14-7cae86e54710","prompt":"你好"}' | /usr/bin/python3 -I ~/.claude/hooks/correction_capture.py | grep -o '【本对话定位[^】]*】'
```

最后两行分别是备份文件的路径和「【本对话定位｜钩子按会话 ID 从 ~/claude/_底座/对话定位.md 附上】」，就是装好了。哪一行报错，就跑下面的撤回命令，把报错发给「用好 Claude｜主对话」。

**核对生效了没有**：在「用好 Claude｜主对话」里发一句：「这条消息的上下文里有没有【本对话定位】？照抄它下面的第一行。」回复照抄出「## 用好 Claude｜主对话 ／ 用好 Claude ／ …」就是生效了。不用重启应用（推断：钩子每条消息都重新运行脚本）。

**撤回**：粘贴这一行，回车，就换回旧脚本。

```
cp ~/.claude/backups/correction_capture_1029旧.py ~/.claude/hooks/correction_capture.py
```

**撤回以后想再装回**：粘贴这一行。跑两次也没关系，备份不会被新脚本冲掉。

```
{ [ -e ~/.claude/backups/correction_capture_1029旧.py ] || cp ~/.claude/hooks/correction_capture.py ~/.claude/backups/correction_capture_1029旧.py; } && cp ~/claude/_底座/设置/correction_capture_新.py ~/.claude/hooks/correction_capture.py
```

**装上以后会自己多出来的文件**：
- `~/claude/_底座/压缩记录.md`：对话压缩一次记一行，11/12 拿来定「压缩几次换对话」。
- `~/claude/_底座/设置/钩子状态/`：记每个对话的会话记录读到了哪里。
- `~/claude/_底座/设置/钩子日志.txt`：只在出错或附加内容超长被截断时记一行。

`~/.claude/settings.json` 不用改，钩子已经登记在里面。

## 二、给另外三个项目各开一个分发

**为什么要开**：每个项目由它自己的分发在后台派活，主对话只收「成品就绪」「待拍板」两种消息，不会被每一轮的通知刷屏。

**怎么开**：在那个项目的主对话里说一句「开分发」。主对话会开出分发（工作文件夹和主对话相同），开完立刻脱离成独立对话，再把开场说明发给它。侧边栏不用新建，也不用粘贴什么。脱离以后，主对话只会收到分发主动发来的消息，不会每一轮都收到通知。

**什么时候说**：规则已改完，现在就可以说。之后也不用一次开完：等那个项目的主对话提醒你（它第一次出现中等或大任务时）再说，第一个先开「弹窗标签推送」。

**抖音号不开分发**：Dk 10/29 原话「不走，照旧」。抖音号照旧由它的主对话自己做，不建任务、不交分发。

| 项目 | 在哪个对话里说「开分发」 | 开出来的分发叫 |
|---|---|---|
| 弹窗标签推送 | 弹窗标签推送｜主对话 | 弹窗标签推送｜分发 |
| 商城活动配置 | 商城活动配置｜主对话 | 商城活动配置｜分发 |
| 团队工作模式 | 团队工作模式｜主对话 | 团队工作模式｜分发 |

团队工作模式的分发不接「给主管的两份成品」，那件由「用好 Claude｜分发」（原名「第二级：分发」）做完交回。

**开好以后核对**：
- 侧边栏本项目分组里有了「项目名｜分发」，没有置顶；
- `~/claude/_底座/项目登记.md` 里，这个项目「分发」那几行有了编号；
- `~/claude/_底座/对话定位.md` 里多了它那一条。

**改名成「（旧，MM/DD）」的旧对话先别归档**：现行主对话可能挂在它下面，归档旧对话会把主对话一起归档。现在就有两个：「（旧，10/29）先看这里」下挂着「商城活动配置｜主对话」，「（旧，10/29）团队工作模式分析」下挂着「团队工作模式｜主对话」。

### 已替你定，可推翻

- **分发的名字**：照各自主对话的名字，把「主对话」换成「分发」。
- **任务目录名**：取项目名。
