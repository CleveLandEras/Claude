# 推送统一后台
- 弹窗
  - 给谁弹：场景内按人群配规则，同属几群只弹最前一条
    - 设多条规则都符合时弹哪条
      - 场景
      - 多条规则都符合时
    - 新建弹窗规则
      - 场景
      - 名称
      - 发送对象
      - 排除群组
      - 预计人数
      - 生效期间
    - 排场景内规则先后
      - 按场景分页签
      - 优先级
  - 弹多少：每天上限、场景间隔、活动次数三层限量
    - 设场景的每天上限
      - 每人每天最多弹几个
    - 设场景的弹出间隔
      - 弹出间隔
      - 不受弹出间隔限制的活动或礼包
    - 设活动或礼包的次数和间隔
      - 每人每天几次
      - 每人两次至少隔多久
      - 各场景的弹出间隔
  - 怎么配：每个活动只配一次，各规则共用
    - 设活动或礼包的弹窗设置
      - 从哪里打开
      - 对应的活动或礼包
      - 宣传图
      - 点击后是否跳转
      - 跳转页面
      - 弹出时机
      - 在所有规则里暂停
      - 另有几条规则在用
    - 选规则弹哪些活动或礼包
      - 可选范围
      - 是否进轮换池
      - 固定的先后
      - 轮换池内顺序
      - 轮换池每次弹几个
      - 每次最多弹几个
      - 本规则另设
  - 怎么验：上架前可测可预览，上架后可查没弹原因
    - 上架前测试和预览
      - 发送测试
      - 按玩家预览
      - 保存确认
    - 管弹窗规则列表
      - 搜索
      - 显示已结束的
      - 按活动或礼包筛选
      - 按发送对象筛选
      - 列表显示的字段
      - 每条展开
      - 操作纪录页签
    - 看弹窗总览
      - 弹出人数、点击率
    - 看单条规则数据
      - 各步人数
      - 没弹的原因
      - 拆分
      - 点击后参考指标
      - 走势标注
    - 看场景数据
      - 同一场景内各规则点击率排名
      - 一次连着弹的第 1、2、3 个的点击率
    - 查某个玩家为什么没弹
      - 按会员编号、昵称、手机号查
      - 各场景下次进入时会弹的活动或礼包
      - 下次进入时轮到哪条规则
      - 轮换池轮到哪个
      - 没弹的原因
      - 近 30 天弹过的
- 推播
  - 发给谁：按群组圈人，发前看到人数
    - 圈发送对象
      - 发送对象
      - 排除群组
      - 预计人数
    - 填推播内容并测试
      - 名称
      - 内容
      - 发送测试
  - 什么时候发：定时或条件触发，夜里不发营销
    - 设定时发送
      - 发送时间
      - 重复
      - 重复至
    - 设条件触发
      - 触发条件
      - 生效期间
      - 每人每天最多收几次
      - 玩家正在游戏里时
    - 设夜间勿扰
      - 时段
      - 适用渠道
      - 勿扰时段内的处理
      - 保存前预估
    - 管推播列表和排期
      - 按发送方式分页签
      - 搜索
      - 日历
      - 状态
      - 每行操作
  - 发多少：营销每人每天限量，重要的优先
    - 设每人每天上限
      - 营销推播
      - 按群组另设营销推播条数
      - 保存前预估
    - 设类别、权重并确认发布
      - 类别
      - 权重
      - 发布确认
    - 看每人每天收到几条
      - 分布
      - 达到每人每天上限的人数
      - 因上限没发人数最多的几条
  - 怎么看效果：可筛选、可对比，逐条看到达和没发原因
    - 看推播总览
      - 发送条数、到达条数、到达率、点击率、到达人数
      - 每天走势
      - 环比
      - 缺数标注
    - 筛选推送明细
      - 每行一条推送
      - 筛选
      - 排序
      - 分组合计
      - 导出
    - 对比几条推送
      - 对比对象
      - 比较时段
      - 基线
    - 看单条推播数据
      - 各步人数
      - 没发出的原因
      - 拆分
      - 发送后参考指标
      - 走势标注
    - 标推播所属活动
      - 所属活动
    - 看活动汇总
      - 按渠道分行
      - 合计人数
    - 查某个玩家为什么没收到
      - 接收状态
      - 近 30 天收到的
      - 没收到的原因
