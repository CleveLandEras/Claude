# 环境打通试用说明（草稿）

**你要确认的只有一件事**：这台 Windows 电脑能装上我们打包的程序，能弹提醒、能粘贴文字、能写日志、能把日志拿回来。后面的自动回复都建在这上面。

全程不碰企业微信，不碰二讲账号，不读任何聊天内容，测试文字是编的。

这些步骤写好后还没在 Windows 上跑过，所以第一次可能有出入。哪一步看到的和这里不一样，截图发回来就行，不用自己排查。

## 开始前

| 项目 | 要求 |
|---|---|
| 电脑 | Windows 10（1809 或更新）或 Windows 11，64 位 |
| 权限 | 普通账号就行，不要管理员 |
| 网络 | 要能上网，第 2、3 步下载用 |
| Python | 这台电脑要装一次，只为打包。打包好的程序不依赖它，二讲的电脑不用装 |
| 文件 | Mac 上的 `/Users/decheng.huang/claude/企业微信自动回复/代码/packaging/输出/自动回复源码.zip` |

总共约 20 分钟，其中第 2、3 步约 10 分钟是等下载和打包。

## 步骤

| # | 做什么 | 应该看到 | 约几分钟 |
|---|---|---|---|
| 1 | 把 `自动回复源码.zip` 传到 Windows 电脑，右键「全部解压缩」到桌面 | 桌面有 `自动回复源码` 文件夹，里面有 `autoreply`、`packaging`，文件名是正常中文 | 1 |
| 2 | 打开 python.org/downloads/windows，下载 Python 3.13 的 Windows installer (64-bit)，双击。第一屏勾选 **Add python.exe to PATH**，取消勾选 **Use admin privileges**，点 **Install Now** | 最后一屏写 Setup was successful | 3 |
| 3 | 双击 `packaging` 里的 `打包.bat`，等它跑完 | 黑窗依次出现 [1/4] 到 [4/4]，最后写「打包完成」，并自动打开一个文件夹 | 7 |
| 4 | 在打开的文件夹里双击 `安装.bat` | 写「安装完成」，桌面多 3 个图标：自动回复测试窗口、自动回复自检、自动回复收集日志 | 1 |
| 5 | 双击桌面的「自动回复自检」 | 黑窗写 **打包 通过／日志 通过** | 1 |
| 6 | 双击桌面的「自动回复测试窗口」，点「测试提醒」按钮 | 屏幕右下角出现标题为 **测试提醒** 的弹窗。趁它还在，按 Win+PrtScn 截整屏，图自动存到「图片\屏幕截图」文件夹；没赶上就再点一次按钮 | 1 |
| 7 | 用记事本打开 `packaging` 里的 `测试文字.txt`，把三段文字依次选中、复制，每复制一段就回到测试窗口按 Ctrl+V 或点「粘贴」按钮 | 窗口依次显示 **已收到 9 字**、**已收到 17 字**、**已收到 26 字**（空格和换行不算字） | 2 |
| 8 | 关掉测试窗口，双击桌面的「自动回复收集日志」 | 黑窗写「已生成」，桌面多一个 `自动回复日志_日期_时间.zip` | 1 |
| 9 | 把这个 zip 和第 6 步的截图，用你平时传文件的方式放到 Mac 的 `/Users/decheng.huang/claude/企业微信自动回复/日志回传/`（没有这个文件夹就新建一个），然后在主对话说一句「日志传好了」 | Claude 核对日志后回你结果，通过的标志是「自检记录 2/2」、1 行 toast shown、3 次粘贴的字数和第 7 步一致 | 2 |

第 5～7 步看到的都对、第 9 步核对通过，这一步就算过了。

## 万一

| 看到什么 | 怎么办 |
|---|---|
| 双击 bat 时蓝框写「Windows 已保护你的电脑」 | 点「更多信息」→「仍要运行」。这是因为文件是传过来的 |
| 杀毒软件（360、火绒、Defender）拦截或删除 `autoreply.exe` | 选「允许」或「信任」。这个程序是刚在本机打包的，没有数字签名，常被误报 |
| 第 3 步写「没找到 Python」 | 第 2 步的 Add python.exe to PATH 没勾上。重新运行安装包，选 Modify 补上，或卸载重装后再双击 `打包.bat` |
| 第 3 步写下载失败 | 这台电脑上不了外网，截图发回来 |
| 第 6 步窗口写「提醒已发出」，但屏幕上没看到 | 多半开了勿扰。在 Windows 设置的通知里关掉「专注助手」或「请勿打扰」，再点一次 |
| 第 6 步窗口写「提醒没弹出来」 | 直接做第 8、9 步，原因在日志里 |
| 第 1 步解压后文件名是乱码 | 截图发回来，先不用往下做 |
