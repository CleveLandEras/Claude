# 合成测试集说明

`合成.jsonl` 是一份全部虚构的家长消息，用来测分类：转二讲（课后服务老师）处理的消息有没有被误判成自动发送。标法依据思考页 7.1 ②（分类规则）、7.1 ⑧（条数）。

**它能说明什么**：这些说法上有没有误发。**不能说明什么**：真实家长消息上的误发率，合成说法不等于真实分布。标注是写的人自己标的，还没有第二个人核对（里程碑 2 第 3 步）。

## 怎么跑

在 `代码/` 目录下：`python3 -m autoreply.dataset_stats 测试集/合成.jsonl`。只用标准库。退出码 0＝条数全部达标，1＝条数不达标，2＝文件读不了或格式有错。每类条数以这条命令的输出为准。

## 字段（每行一个 JSON 对象）

| 字段 | 类型 | 含义 |
|---|---|---|
| `id` | 字符串 | 唯一编号，如 `syn-0001` |
| `text` | 字符串 | 原话。连发合并后的消息用换行分隔（思考页第 6 节第 6 条） |
| `label` | 字符串 | 正确类别，10 个之一，见下表 |
| `mixed` | 布尔 | 是否混合消息 |
| `tricky` | 布尔 | 是否刁钻说法 |
| `parts` | 字符串列表 | 混合消息里的各个成分类别；不是混合消息时为空 |
| `note` | 字符串 | 刁钻句写明为什么这样标，供核对；其他行为空 |

## 类别

处理方式由 `label` 决定，不单独存字段。

| label | 处理 | 怎么判 |
|---|---|---|
| 上课时间 | 自动 | 问下节课或某天几点上课、在哪上、要课表 |
| 回放链接 | 自动 | 问回放、重播、错过了在哪看 |
| 作业截止 | 自动 | 问作业几号交、截止时间、还能不能交 |
| 请假调课 | 自动（只答规则和流程） | 说要请假、调课、换时间，只影响某几节课 |
| 学科答疑 | 转二讲 | 问具体题目、知识点，或附题目图片 |
| 续报 | 转二讲 | 续费、下学期、报名、优惠，含委婉试探 |
| 退费 | 转二讲 | 退费、退款、不想上了要结算，含没出现「退」字的说法 |
| 投诉 | 转二讲 | 要追究或向上反映：投诉、不满意、找领导、要说法、换老师 |
| 带情绪 | 转二讲（对齐卡原文「带情绪的消息」） | 只发泄不满，没提出追究：指责、反问、讽刺、负面词 |
| 都不是／拿不准 | 转二讲 | 上面 9 类都不是，或看不出是哪类：寒暄、感谢、催促、广告、问孩子学情、指代不清、非文字消息 |

## 混合和刁钻怎么标

- **混合**（`mixed: true`）：一条消息里有两个彼此独立的诉求，拆开各归一类，如既问作业截止又问题目、事务句后面跟一句发火。按思考页 7.1 ② 整条转二讲，所以 `label` 永远不是自动类；`parts` 留着各成分，提醒二讲时可附事务部分的建议答案。
- **刁钻**（`tricky: true`）：只有一个诉求，但字面像别的类，看关键词会判错。分两个方向：
  - 看着像事务、其实该转二讲（反问、讽刺、委婉的续报或投诉、藏起来的退费）。判成自动就是误发，这个方向最要紧。
  - 看着像转二讲、其实是事务（「今天不上了，请个假」「退出直播间了，回放在哪看」）。判成转二讲只算漏答，不算误发。
- 事务句如果只是铺垫，为同一个诉求服务（「最后一节课是几号？上完我们就不来了，后面的费用想问问」），算刁钻，不算混合。
- 两个标记可以同时为真：事务在前、委婉的退费或投诉藏在后半句。

## 替分发定的（思考页没写死，可推翻）

1. **一条里有两个自动类**（如既问上课时间又要回放）：思考页 7.1 ② 第 3 步写「只命中自动 4 类中的一类」才往下走，所以这种转二讲。`label` 标「都不是／拿不准」，`mixed` 为真，`parts` 列两个自动类。
2. **一条里有两个转二讲类**：`label` 按投诉 > 退费 > 带情绪 > 续报 > 学科答疑取一个，`parts` 全列。这个次序只影响提醒里显示哪类，不影响是否误发；后面算分时，判成 `parts` 里任一转二讲类都可算对。
3. **「另加混合消息和刁钻说法各 30 条」（思考页 7.1 ⑧）**：按严的读法，扣掉混合和刁钻后，普通条也要满足「转二讲每类 ≥ 30、合计 ≥ 150、总数 ≥ 300」。`dataset_stats` 两种读法都查。
4. **客气话加事务不算混合**：「上节课的回放发我下 谢谢」只标回放链接。寒暄单独成句才归「都不是／拿不准」。
5. **非文字消息**：用占位写法 `[图片]`、`[语音]`、`[文件]`，表情用 `[捂脸]` 或 Unicode 表情，都归「都不是／拿不准」；文字加图片（`[图片] 这题`）按文字归类。企业微信界面读出来到底是什么样，要等里程碑 1 实测，到时再改占位写法。
6. **误发怎么算，留给里程碑 2 第 5 步**：思考页那一步的 `misfire` 只数转二讲 5 类。「都不是／拿不准」也该转二讲（思考页第 6 节第 5 条），7.1 ⑧ 的误发率定义「本该转我」也包括它。建议把这一类也算进 `misfire`，或单列一个数；本步只负责把类别标出来。

## 虚构约定

- 姓名只用明显虚构的：王小测、李小样、赵例例，以及小测、样样、例例这类小名。
- 手机号只用 `13000000001`～`13000000005`（含带横线的写法），单测会检查没有别的手机号。这些句子也供后面测去标识化。
- 没有真实机构、老师的名字。`12315`、消协、教育局是家长常提的公开投诉渠道。
