# 产品计划原文（Dk 10/10 转述，繁体原文）

產品計劃：短期提升直觀體驗內容，中期目標提升 外贈掉落/推送規則等
短期計劃：

1. 彈窗功能：滿足不同用戶下的彈窗內容，并整體控制彈窗 數量/內容/順序等
   1. 針對 新增 / 回流 / 破產 / 潛在付費 / 潛在流失用戶 逐步設計 客製化彈窗內容
   2. 優先進行已有功能滿足內容，功能不滿足部分，排期補充
2. 推送：統一推送入口，提高易用性，并增加數據情況（發送量，到達率等）
3. 標籤能力：針對現有標籤能力進行補充，并根據產品側使用情況持續優化
   1. 現有「And」、「排除」，新增「or」，後續增加「交集」

中期計劃（優先進行「成就系統」和「銀行功能改造」）：外贈（掉落）功能、好康活動、成就、銀行功能改版（商城方向）、裂變+回流、功能梳理、每日任務框架。

注：本方案范围是短期计划三项。Dk 10/10：我们的短期/中期/长期与此同义；推送统一入口属短期。「或」据盘点已上线。
