- **链位按实际命中谁判**，不按卡名判（卡上陷阱 1）。
- **判读规则 1–8**（照卡原文，按顺序套用，先命中者为准）：
  1. 删：不服务任何链位；诊断已推翻它的前提；与已证实的配置事实矛盾且改了也不服务链位。
  2. 改：服务链位，但现写法的对象、次数或内容与链位不符。写改的方向，不写配置值。
  3. 并列待定：服务链位只在 D4b（或 D4b 与 D2）→ 不降级，标「这会成为哪个决策点」。
  4. 降级（保留为次要，不进首期）：服务链位只在 D3、D2、D6、D7，或本地证据只到「够得着、作用未知」。零成本例外：现有配置即可、无新增弹出次数、无已知风险的，可判「保留（次要）」。
  5. 保留 / 新增：服务 O1 其余、D1、D8 独有或 O4，且实现方式为「现有配置」或「配置有前提」。
  6. 开发项：判「推后（开发）」，除非服务 O1 或 D1 且没有配置替代 → 「保留（需开发，交主管）」。
  7. 五类人群卡是否仍是主线：数 02 五张卡中判「保留」或「改」且服务 O1 或 D1 的张数：≤ 1 张 → 不再是主线；2 张 → 部分仍是；≥ 3 张 → 仍是主线。
