# A13 八月离开的用户：他们是谁，和还在的人差在哪

脚本：`_scripts/an_q42_churn.py`（只读，不带参数）｜设计卡：`过程记录/设计卡.md` Q42｜2026-09-28 执行轮

## 结论

**8/1–8/15 最后登录、到 9/16 已 32–46 天没来的 12,188 人，构成和近一月里「15–31 天没来」的人几乎一模一样（卡别、储值率、押注、潜在付费、平台，差距都不到 5 个百分点）：97% 是普卡，金卡以上只有 173 人，历史累计储值合计约为还在的人的 1.92%（其中三分之二在这 173 人身上）；离开的人里 27.34% 是 8 月上半月才注册的，那一批注册者 46.49% 只来了注册当天——A12「一半新增只来当天」的发现在更早一批注册者上重现。** 构成数字为已证实（本快照）；「与 15–31 天档是同一条曲线的延续」为推断；「金卡以上离开人数可能被低估」只有一个弱信号，扣除基线后约 13–27 人，把疑似者全算上最多约 236 人（推断，升级门槛已证实（储值或押注任一达标、钻石以上另需会员等级，会员报告），累计周期倾向近两个月（推断），降级规则待运营第 2 句，Q53、R83 改；原写「按储值画像的参考数约 236 人」，按审查 R65 更正）。

## 方法与口径

- 数据：`数据/八月登录流失名单_20260916.csv`（29,242 行）、`数据/近一月活跃_20260916.csv`（63,032 行），各自剔除身份为機器人、測試帳號的行后为 28,894 行、62,292 人。
- **离开者** = 流失名单中会员编号不在活跃里的人，**12,188 人**（数据说明的 12,269 为剔除前）。
- **合并口径** = 活跃 62,292 + 离开者 12,188 = **74,480 人**，即「8/1 以后登录过的全部人」。重叠的 16,706 人一律用活跃文件的值，不重复计数。
- 天数：最后登录日期距 9/16 的天数，9/16 为第 0 天；注册天数同理（与 A8 一致）。四档：活跃 0–7 天（8 个自然日）、8–14 天（7 日）、15–31 天（17 日），离开者 32–46 天（15 日）。档宽不同，比人数用日均，比构成用占比。
- 卡组：普卡 = 1，银卡 = 2，金卡以上 = 3–7。平台：App 类 = android、ios、apk；浏览器类 = mweb、web、h5、mh5；大写 Web 并入 web。潜在付费代理：累计储值 ≤ 0 且累计押注 > 10,000。
- 金额（储值、押注）都是账号历史累计值，不是离开前的月度值。

## 局限

1. **只覆盖半个月的离开者**：最后登录在 8/1 以前的人不在任何一份数据里。「8/1–8/15 离开的人里高卡少」不等于「高卡很少流失」；表 2 的比例不是流失率。A8 局限 1「看不到已经走了的高卡用户」**只被部分补上**：补上了最后登录在 8 月上半月的那一段，更早离开的仍然看不到（幸存者偏差倒过来：离开者本身也是「8 月还来过」的人）。
2. 32–46 天没来不等于永久流失：重叠者里有 5 人名单显示 8/1–8/15 最后登录，两小时后的活跃数据里已登录到 9/16。本文说的是「截至取数已 32 天以上没来」。
3. 储值、押注是历史累计，不是离开前的月度付费；「约为活跃的 1.92%」是存量比，不能说成「流失造成的收入损失」。
4. 卡别、会员等级是取数时的值；降卡只能看到一个弱信号（S4）。
5. 一个月的快照，是否每月都这样要等 7 月名单（推进计划「给 Dk」第 3 条）。
6. 押注、储值字段本身的口径问题（原问题 25 d，现不再追问，引用时带影响方向，A12 第五节）同样适用于离开者。（原写「问题 25 d，A12 第五节」，按审查 R70 更正。）

## 对哪条诊断意味着什么（只描述，不判断可干预性）

- 环节2 给「高卡流失」「新增流失」排影响规模时，要用这组数，而不只是活跃里「最后登录 8 天以上」的人：8 月上半月离开的金卡以上 173 人（降卡造成的低估不大：超出基线约 13–27 人，236 是全部算上的上限；原写「按储值画像约 236 人」，按审查 R65 更正）、累计储值约为活跃的 1.29%；同期离开的 8 月新注册者 3,332 人，其中 2,407 人注册当天之后就没再来。
- 「只来一天」不是某一个月的偶然：两批注册队列都在 46–50%。
- 离开者和「15–31 天没来」的人是同一副样子：环节2 如果要给「较久没来的人」画像，两组可以合并看；构成的变化主要在「最近一周来过」与否之间，但这部分来自按最后登录分档本身，不能直接当流失预警阈值（R66）。
- A8「还在但 8 天以上没来」的金卡以上 757 人与本文离开的金卡以上 173 人不重叠：前者 8/16 以后来过，后者 8/15 以后没再来。
- 推送线：离开者按定义不在线，快显够不着，只能靠推播、短信、LINE、Facebook 这些站外通路（问题 9 更正版；各通路覆盖与定向能力未知）；他们的平台构成与还在的人相同。
