## 第二部分　输赢与高卡「8 天以上没来」

### 方法与口径

- 人群：高卡（卡别 3–7，剔除身份 VIP、黑名單），近一月活跃文件，6,299 人；结果变量：最后登录距 9/16 满 8 天（8–31 天）为 1，0–7 天为 0；整体 8 天以上没来 755 人（11.99%）。
- 主分析：先按累计押注分四档，再在每档内按 RTP 排名分四等份（档内排名，控制押注）；D = 档内最低 25% 的比例 − 档内中间两份的比例；合并 D 按各档最低 25% 的人数加权；95% 区间用正态近似。U 形检查 D′ = 档内最高 25% − 中间两份。
- 分母：各格人数写在表里（每档 1,574–1,575 人，档内最低 25% 各 394 人）。

### S1 复现（试算 18.1% / 10.7% / 8.4% / 10.6%）

全体高卡按 RTP 四等份（1 = 最低）：18.2% / 10.7% / 8.4% / 10.6%，各份 1,575 / 1,575 / 1,574 / 1,575 人。比例与试算相差 ≤ 0.1 个百分点；人数与试算（1,577 / 1,573 / 1,579 / 1,570）差几个人，是因为试算按数值分位（同值的人可能落在同一份），这里按排名等分，**不是口径不同，复现通过，继续**。

### S2 主分析与 S3 U 形检查

| 累计押注档 | 档人数 | 档内最低 25%（人数 / 8 天以上没来比例） | 中间两份比例 | **D**（百分点） | D 的标准误 | D′ |
|---|---:|---|---:|---:|---:|---:|
| 第 1 档（最少） | 1,575 | 394 / 23.4% | 15.9% | **+7.5** | 2.5 | −3.4 |
| 第 2 档 | 1,575 | 394 / 19.0% | 11.3% | **+7.7** | 2.3 | +1.1 |
| 第 3 档 | 1,574 | 394 / 12.9% | 8.0% | **+4.9** | 1.9 | +3.7 |
| 第 4 档（最多） | 1,575 | 394 / 9.1% | 5.8% | **+3.3** | 1.7 | +2.8 |
| **合并** | 6,299 | 1,576 | — | **+5.85（95% 区间 +3.77 ~ +7.93）** | — | **+1.03** |

读法：同一押注档内，输得最多的四分之一比中间一半更常 8 天以上没来；押注越少差距越大。最高 25% 的 D′ 合并只有 +1.03（不到 D 的一半），不像 U 形。

### S5 敏感性：并入八月流失名单里的高卡离开者

流失名单里高卡 514 人，其中只在名单里（8/1–8/15 最后登录，已 32–46 天没来）的 172 人算 y = 1、其余沿用活跃文件的值，共 6,471 人。合并 D = **+6.73**（95% 区间 +4.56 ~ +8.90）；四档 D：+11.1 / +8.5 / +4.7 / +2.7（3 档 ≥ 3）。与 S2 判读一致（取较保守的一个，S2）。

### 反例检查

1. 押注十等份内排名代替四等份：合并 D = +4.14（与 +5.85 相差 1.7 个百分点，未超过卡上 2 个百分点的门槛，不写「对分档方式敏感」）。**但按规则 2 的门槛（≥ 5 为「有关联」、3–5 为「不定」），+4.14 落在「不定」区间；各押注档内 RTP 最低组的押注中位数只有中间组的 0.46 / 0.92 / 0.96 / 0.75 倍（审查复算），第 1、4 档仍有「玩得少」的残余混杂**，所以「押注相同」只能读作「同一四分档内」，结论强度写「有关联（四分档下），更细控制后减弱」。提案一节（推荐乙：监测列）不受影响，它本来只到监测。
2. 普卡、银卡（55,870 人）做同样的 S2：合并 D = +3.08（四档：+0.5 / −1.7 / +6.0 / +7.5）。**不是只有高卡有**，方向相同但更弱（只报，不改判）。

### S6 量级（只写上界式估算）

- 各押注档内输得最多的四分之一的高卡合计 1,576 人，其中 0–7 天在场 1,322 人（弹窗碰得到的一段，只描述）、8 天以上没来 254 人。
- 超额约 **92 人**（合并 D × 1,576，推断，相关不是因果；不写「输赢导致流失 92 人」）。
- 这 1,576 人的累计储值占全平台（62,292 人）累计储值的 24.59%，历史月均口径 24.91%；其中 8 天以上没来的 254 人占 2.64%。这是「高卡 8 天以上没来」这一层（755 人，累计储值占 6.10%；A16 含已离开者为 7.18%）的一部分，**不能与 D1、O1 或其他项相加**。

### 判读规则命中

1. 复现不过就停：通过。
2. 关联是否在同押注下仍存在：合并 D +5.85 ≥ 5，且 4 个押注档 D 都 ≥ 3 → **「在同一押注四分档内的高卡里，输得最多的四分之一更常 8 天以上没来」（推断：相关，不是因果；四分档下成立，十等份下 +4.14 属「不定」，见反例检查 ①）**。
3. U 形降级：D′ 合并 +1.03 < D 的一半（2.93）→ 不降级。
4. 方向一致性：6 个分层格 D 全为正 → 不加「分层后方向不稳」（但卡 5–7 约为 0，单列写明）。
5. 敏感性翻转：S5 与 S2 判读相同，取较保守的 S2。
6. 量级措辞：见 S6，只写超额约 92 人的上界式估算。

## 结论边界与局限

- 能说（已证实，本快照）：各格人数与比例、列扫描事实、清单。能说（推断）：同押注下关联存在与方向、超额人数的上界式估算。**不能说：**「输多了导致高卡流失」；「近期输钱会让人不来」（RTP 累计）；「8 天以上没来 = 流失」（有隔周来的人，A27 局限 3）；「给输多的高卡弹 X / 发 X 能留住人」；把超额人数与 D1、O1 相加。
- 其他解释：玩法偏好（累计 RTP 低可能是长期玩返还率低的游戏，没有游戏明细，不可排除）；时间顺序（RTP 是累计值，不可排除）；「8 天以上没来」只含 8/16–9/8 最后登录的人，8 月上半月离开的已在 S5 并入。
- 局限：只是一个快照；押注、RTP 的统计范围受押注字段漏记影响（A11、A12，影响方向已写）；分四等份与十等份结果相差 1.7 个百分点。
