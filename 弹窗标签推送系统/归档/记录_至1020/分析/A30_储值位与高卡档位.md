# A30 N1 的前提与分档：在场高卡储值位现在先看到什么、与他们的付费档位差多远

队列项：推进计划 Q93｜设计卡 Q93｜脚本 `_scripts/an_q93_tier.py`（只读；人群定义照 `an_q77_opp.py`，import `an_q76_perf.load`，不另定义）｜环节3 方案｜2026-09-29

## 结论（一句话：规则 1 的句子 + 规则 2 的分档 + 规则 4 的两句条件句）

- **前提（规则 1）**：储值位现在先给在场高卡 NT$50 的人数，本地只能确定 **25 人（0.49%）**，其余取决于是否买过首储（本地判不了）。上界约 **5,145 人**，只有 1 人能确定买过首储。所以 N1 的前提「待确认」，本地既不能确认也不能否定。
- **分档（规则 2）**：卡 3 与卡 6+7 的月均储值中位相差 **8.7 倍**；只看注册 3 年以上的老账号，仍相差 **15.0 倍**。一个高卡规则放一个礼包，不能同时对上两端，**N1 至少分两档（推断）**。相邻两档的重叠都在 27–35%，卡别只是档位的粗略代理。
- **缩窄的条件句（按门槛区间写，从 0 元写到最高门槛；门槛取表 2 各档 R 的 P25 / 中位，审查 R137、R139）**：储值位第一个礼包（买过首储后是独享礼包）的价格——
  - **约 74 元以下**：四档都判「偏低」，上界 **5,146 人（100%）、R 底盘 100%**（与表 4 的 P = 50 列一致；现首储礼包 NT$50 就在这一格）；
  - **约 74–160 元**：卡 4、卡 5、卡 6+7 判「偏低」（卡 3 不定），上界 **3,446 人（66.96%）、R 底盘 84.32%**；
  - **约 160–300 元**：卡 5、卡 6+7 判「偏低」，N1「往上调」对这两档有方向依据，范围上界 **1,827 人（35.50%）、R 底盘 55.07%**；
  - **约 300–690 元**：只有卡 6+7 判「偏低」，上界 **662 人（12.86%）、R 底盘 25.53%**；
  - **约 690–1,360 元**：没有一档判「偏低」，卡 6+7 不定；
  - **约 1,360 元以上**：四档都不偏低。
  - 卡 5 的门槛（P25 = 300.2 元）与锚点 300 几乎重合；老账号口径下卡 5 在 300 元已是「不定」（反例检查 ②）。所以 1,827 人、55% 只在约 160–300 元成立（更低时范围更大，更高时只剩卡 6+7），不代表「几百元」整个价格带。

证据强度：人数、分位、注册月龄 → 已证实（本快照）；分档、价格对照、缩窄范围 → 推断（条件式）；是否买过首储、礼包实际价格、储值位对高卡的作用 → 待确认。

## 方法

1. **R 是「历史月均」，不是月储值，也不是单次付费。** R = max(累计储值, 0) ÷ max(账号月龄, 1)。R = 400 可能是一次付 400，也可能是八次付 50。价格对照只能说明「这个价格相当于他平均一个月花多少」，不能说明他愿意一次付这么多（其他解释 4）。
2. 人群：O1 在场付费者 13,368 → 去掉按 R 排前 1% 的 134 名大户 → 其中金卡以上 **5,146 人**（S1 复现通过）。分四档：卡 3、卡 4、卡 5、卡 6+7（6、7 合并，与 Q90 一致）。已剔除机器人、测试账号、VIP、黑名单。
3. S1 下界：充值赠点 < 15,000 → 确定没买过首储（A19 推理，前提是首储点数一直 ≥ 15,000、点数不扣回）。「确定买过首储」：累计储值恰为 50 且赠点为 16,800 或 15,000（A10 指纹）。上界 = 5,146 − 确定买过首储。
4. S3 价格锚点 P ∈ {50（首储，已知）, 300, 1,000, 3,000}。**300–3,000 是盘点里「大多数礼包在几百到三千之间」的价格带锚点，不是任何一个礼包的实际价格。**
5. 判读规则 1–6 照卡原文（见设计卡 Q93），按顺序套用。

规则 3 的措辞：
- 偏低：该档四分之三的人平均每月花得比这个价格多，N1 往上调对该档有方向依据（推断）。
- 不偏低：该档过半数人平均每月花得比这个价格少，N1 往上调对该档没有依据，可能反而偏贵。
- 不定：介于两者之间。

**反例检查 ②（只看注册 3 年以上的老账号）**：判断更保守。卡 3 在 P = 50 时变为「不定」（P25 43.8，中位 76.3）；卡 4 在 P = 300 时变为「不偏低」；卡 5 在 P = 300 时变为「不定」；卡 6+7 不变（300 偏低，1,000 不定）。也就是说，在老账号口径下，P = 300 时有稳定依据的只剩卡 6+7。

## 对 N1 意味着什么

- **N1 写法**：从「在场高卡储值位按卡组拆（一个金卡以上规则）」改为「至少分两档」，切法随价格定：约 160 元以下可切卡 3 / 卡 4–7（74 元以下各档都偏低，仍按 8.7 倍分两档），约 160–300 元可切卡 3–4 / 卡 5–7，约 300–690 元时切卡 3–5 / 卡 6–7（卡别标签现成，分档仍是配置，依赖 A28 第 3 行的「当前卡别」标签条件）。具体怎么切、放什么礼包，等运营与自查 ①，本文件不定（「明确不做」）。
- **N1 是否缩窄**：取决于储值位第一个礼包的实际价格（自查 ①），按上面的门槛区间判：约 74 元以下，往上调对四档都有依据（上界 5,146 人、R 底盘 100%）；约 74–160 元，对卡 4–7（上界 3,446 人、84%）；约 160–300 元，对卡 5–7（上界 1,827 人、R 底盘 55%）；约 300–690 元，只对卡 6+7（上界 662 人、26%），老账号口径下 300 元时也只剩卡 6+7；约 690–1,360 元，没有一档判「偏低」（卡 6+7 不定）；更高则四档都不偏低。价格高到没有一档判「偏低」时，N1 往上调对各档都没有「偏低」的依据，N1 的去留交决策点。**本文件不能据此降级或确认 N1 整体**（规则 1、结论边界），只改分档和各档的条件式去留。
- **与 A26 的关系**：A26 N1 判「新增」依赖规则 4 的一处解读（审查 R128）。A30 不涉及那处解读，但说明 N1 即使保留，适用范围也可能明显小于 5,146 人。

## 证据强度

- 已证实（本快照）：各档人数、R 分位、注册月龄；赠点 < 15,000 的 25 人（在「首储点数 ≥ 15,000、点数不扣回」前提下即确定没买过首储）。
- 推断（条件式）：至少分两档；各价格锚点相对各档是否偏低；缩窄后的人数与底盘上界。
- 待确认：是否买过首储、礼包实际价格、储值位对高卡的作用。

## 局限

1. R 不是月储值，更不是单次付费（方法第 1 条）；价格对照只作「相当于平均每月花多少」的比较。
2. 同卡别内部跨度大（表 3：同卡别注册一年内与三年以上差 10–15 倍，部分来自 R 的算法）；按卡别分档只对得上各档的中间。
3. 价格锚点不是实际价格；独享礼包与其他礼包的价格、限购都没有。
4. 没有曝光和点击：储值位对高卡是不是主要付费入口，本地排除不了（其他解释 3）。
5. 不追查独享礼包限购、首储开放期、卡别定级规则（陷阱 7）。
6. 表 4 只有四个锚点列；锚点之间的判定按表 2 的 P25 / 中位推（结论第 3 条的门槛区间），锚点只作示例。
