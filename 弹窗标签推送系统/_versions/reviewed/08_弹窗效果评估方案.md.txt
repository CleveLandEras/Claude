## 〇点五、判读规则（通用，事先约定；与 02 附录六一致）

1. **每项一个主指标**，落在业绩的对应环节上，按分到该组的全部人算；参与、购买、点击是过程指标，不能当主指标。
2. **对照方式决定最高能判到哪一档**：有随机对照时三档都能判；只有切换前后比较（路 C，加同期参照）时，主指标最多判到「方向一致（推断）」或「看不出」，不判「过」，因为同期活动排期、每月 1–7 日加码、季节混进差值；路 C 下护栏仍可判「不过」，回退是改回配置，回退后要复看。
3. **主指标和统计型护栏都只在两个时点判**：第 1 期末（各指标原定窗口）主指标与护栏都用 99% 区间；不到结论就延长，合并 3 期后主指标用 95% 区间、护栏仍用 99% 区间终判，之后不再延长。非判读时点，统计型护栏每期都看、只报数、不判；曝光类护栏（M7 对照 02 上限表、单次破产仍弹 1 个）是配置核对，每期都看，超上限就查是哪条规则叠加、改那一条。真实没有效果时，按本规则一张卡被误撤的概率约 4%–7%，误判「过」约 3%（第一张卡两个子人群任一过即判过，约 5%）；这是事先约定的取舍，数为设计者按独立近似估算的上界式情景值（A36 第一节）。判读线在同一版的判读期内不改，要调只对下一版生效。**第一张卡的两个判读时点（第 1 期末、合并 3 期末）都定在该期（合并时为第 3 期）队列最后一日 + 13 日，也就是 14 天储值取齐之日，比留存取齐晚 6 日；这一天同时判 M2、M3、储值护栏、M8，留存取齐后只报数（Q166）。其余卡不变。**
4. **三档与判读顺序**（随机对照下，差 = 处理组 − 对照组）：每个判读时点依次判，前一支成立后面不再看：**不过** = 任一统计型护栏突破，或差小于 0 且区间不含 0 → **过** = 差大于 0 且区间不含 0 → 卡别专用支（目前只有第四张卡的「挪量」，是与「不过」并列的另一支）→ **看不出** = 以上都不是，再按过程指标分「保留」（第 1 期末延长；合并 3 期终判继续运行，判读期结束，不再延长判读）与「改内容，不改结构」两格。**对照组去向（随机对照下，Q166；路 C 没有对照组，不适用）：过 → 保留，对照组转全量。看不出 → 第 1 期末延长，对照组照留；合并 3 期终判落「保留」→ 同样转全量，但结论只写「看不出（点估计 +x%，区间 a–b），保留为现行版」，不写「过」「有效」，只在「过」之后才做的动作（提案乙「往上调一档」）不做；落「改内容」→ 对照组照留，下一版从新的第 1 期重新计判读期，判读线按下一版。不过 → 回到现状（处理版停用），对照组无需改动。转全量 = 该卡改用 03 该行的「退路（全量）」写法，停用处理版和对照组专用写法；各卡共用一个「分桶·处理」标签，一张卡转全量只改这张卡的规则，不动标签，其余卡的对照照旧。**
5. **统计型护栏突破**：随机对照下，处理组比对照组朝坏的方向变、且两个判读时点的 99% 区间不含 0；路 C 下，比率类（留存、再登录、关闭率）变差 3 个百分点以上（同样只在两个时点判），金额类护栏（第一张卡储值护栏）路 C 下只看不判；曝光类高于 02 上限表、高于现状属配置核对。**3 个百分点是事先约定，Dk 可在上线前改。**
6. **可检测幅度**只说这一项在现有人数下能看出多大的变化，不用来排方案、降级或推后；预期变化小于可检测幅度时，主指标大概率落在「看不出」，判读主要靠过程指标与护栏。
7. **事先约定、Dk 可在上线前改的判读线**：主指标与护栏的 99% / 95% 门槛和判读时点；护栏 3 个百分点；「购买人数不到对照组同一位置的一半」；第二张卡档位 5% 与 40% 宽窄线（后者是上线后调档位的规则，不属判读线）。判读线在同一版的判读期内（第 1 期末到合并 3 期终判）不改，要调只对下一版生效。
8. **按触发位判的卡（第四张卡）**，「分到该组的全部人」指分到该组、窗口内触发过（破产）的全部人。
