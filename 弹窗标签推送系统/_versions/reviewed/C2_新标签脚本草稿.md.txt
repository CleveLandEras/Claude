## 二、标签「从未储值」

| 项 | 内容 |
|---|---|
| 用途 | 潜在付费人群规模统计；与现有标签「近 4 个月来的投资总额超过 10000」以 And 组合，圈出潜在付费 |
| 对应 | 02「潜在付费沿用储值位首储礼包」前置条件；08 潜在付费首储购买率（M5）的分母 |
| 口径 | 账号累计储值金额为 0，不限是否活跃。与近一月活跃用户的交集即 02 所用 44,027 人（62,292 − 有储值 18,265），统计规模时须再叠加活跃条件 |
| 建议刷新频率 | 每日 1 次。不作弹窗对象，只用于规模统计；08 M5 两侧名单按 09 表5 以窗口首日为截止日重算，不取该标签留存，不另建快照 |
| 现有标签替代 | 盘点附录一「身份 / 状态」类有现有标签「已经先存储了」。若其口径为累计储值金额大于 0，排除该标签即得「从未储值」，无需上线新脚本；口径以问题 11 答复为准 |

```sql
SELECT DISTINCT m.【待核对：会员编号】 AS user_id
FROM `prod-439407.o8richonline_cdc.【待核对：会员表】` m
WHERE COALESCE(m.【待核对：累计储值金额】, 0) = 0
  AND NOT (【待核对：机器人或测试账号的判定条件】);
```

## 三、标签「身份非新增、非回流」

| 项 | 内容 |
|---|---|
| 用途 | ID5 活动类弹窗的对象 |
| 对应 | 02「活动位按玩家身份拆分」前置条件；08 各人群人均每日弹窗曝光数（M7）中的「其余」人群 |
| 口径 | 身份为持续、VIP、黑名单，与 02 附录二「其余」一致；近一月活跃 34,979 人（分母 62,292） |
| 启用条件 | 弹窗对象不支持带排除条件的群组时启用；支持时 ID5 对象直接配置为全部玩家排除新增、回流，不需要此标签 |
| 建议刷新频率 | 最快 25 分钟，并与标签「新增」「回流」同频。三个名单刷新不同步时，身份刚变更的玩家可能同时命中 ID5 与回流用户活动弹窗，单次进大厅弹出数超过 02 所定上限 3 个；也可能三条活动类规则都不命中 |

```sql
SELECT DISTINCT m.【待核对：会员编号】 AS user_id
FROM `prod-439407.o8richonline_cdc.【待核对：会员表】` m
WHERE m.【待核对：身份】 IN (【待核对：持续、VIP、黑名单三个身份的取值】)
  AND NOT (【待核对：机器人或测试账号的判定条件】);
```

## 四、潜在流失名单快照

| 项 | 内容 |
|---|---|
| 用途 | 按日保存标签「当月储值额小于上月储值额 50%」名单内的活跃用户及其当日卡别、身份。每月最后一日的记录供次月观察储值变化；每日记录供判定当日的潜在流失人群 |
| 对应 | 02「潜在流失定向覆盖全部卡别」评估重点；08 潜在流失回升率（M4）的分母：取圈入月最后一日的记录（标签若以当月 1 日起的累计储值与上月全月比较，月初名单会圈入多数付费用户），按身份限定其余（持续、VIP、黑名单），按卡别拆为普卡银卡、金卡至至尊卡两组；08 M7 与 09 表8 的潜在流失人群：取当日记录 |
| 口径 | 活跃用户：最后登录时间在近一个月内，与 02 附录二分母口径一致。该标签名单不落表时，FROM 子句中的结果表改为该标签脚本的查询 |
| 建议刷新频率 | 每日 23:30（台北时间）执行一次；同日已有记录时不再写入，重跑不产生重复行。该标签的排程若晚于 23:30，写入的是前一次刷新的名单，执行时间须移到该标签当日最后一次刷新之后；排程以问题 11 答复为准 |
| 覆盖起点 | 快照自首次执行日开始累积。08 M4 切换前组的圈入日（D0 所在月往前第 2 个月月末）、M7 切换前窗口（D-14 至 D-1）早于首次执行日时，对应名单无法由快照取得，该指标两侧均按 09 表4、表8「名单来源」重算 |

```sql
CREATE TABLE IF NOT EXISTS `【待核对：快照表所在数据集与表名】` (
  snapshot_date DATE,
  user_id 【待核对：会员编号的字段类型】,
  card_tier 【待核对：当前卡别的字段类型】,
  identity 【待核对：身份的字段类型】
);

INSERT INTO `【待核对：快照表所在数据集与表名】` (snapshot_date, user_id, card_tier, identity)
SELECT
  CURRENT_DATE('Asia/Taipei') AS snapshot_date,
  t.user_id,
  m.【待核对：当前卡别】 AS card_tier,
  m.【待核对：身份】 AS identity
FROM `prod-439407.o8richonline_cdc.【待核对：标签「当月储值额小于上月储值额 50%」的名单结果表】` t
JOIN `prod-439407.o8richonline_cdc.【待核对：会员表】` m
  ON m.【待核对：会员编号】 = t.user_id
WHERE DATE(m.【待核对：最后登录时间】, 'Asia/Taipei')
      >= DATE_SUB(CURRENT_DATE('Asia/Taipei'), INTERVAL 1 MONTH)
  AND NOT (【待核对：机器人或测试账号的判定条件】)
  AND NOT EXISTS (
    SELECT 1 FROM `【待核对：快照表所在数据集与表名】` s
    WHERE s.snapshot_date = CURRENT_DATE('Asia/Taipei')
  );
```
