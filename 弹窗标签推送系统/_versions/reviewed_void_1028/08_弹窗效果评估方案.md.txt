# 弹窗效果评估方案

2026-09-27

---

## 一、对比设置

| 项 | 规定 |
|---|---|
| 切换日 D0 | |
| 对比方式 | 切换前后对比；D0 当日数据不计入任一侧；日期按台北时间（Asia/Taipei）自然日，注册日、回流判定日记为第 0 日 |
| 基本窗口 | 切换前 D-14 至 D-1，切换后 D+1 至 D+14，两侧均为两个整周 |
| 储值类窗口 | 两侧各取 14 个不落在每月 1–7 日的自然日：切换前自 D-1 起往前取，切换后自 D+1 起往后取；两侧天数相等，按窗口合计比较。每月 1–7 日限时加码礼包不出现，ID6、ID7 的取值结果与其余日期不同 |
| 统一剔除 | 机器人、测试账号，与 02 附录二分母口径一致 |

归因限制：弹窗后台支持实验分流，开发成本未评估，02 未采用分流。切换前后差值包含同期活动排期与月内周期的影响；只有潜在流失回升率（M4）具备同期参照组。

## 二、指标（不依赖埋点）

### 回流任务参与率（M1）

对应决策项：活动位按玩家身份拆分

| 项 | 内容 |
|---|---|
| 指标定义 | 窗口内有回流任务参与记录的回流身份用户数；同时报告人数与比率 |
| 分母 | 窗口内有登录、且登录当日身份为回流的用户数 |
| 对比方式 | 切换前后 |
| 对比窗口 | 基本窗口内回流任务处于开放期的日期；两侧开放日数不等时，较多一侧只取离 D0 最近的同等天数 |
| 数据来源 | 回流任务参与记录；会员登录与身份记录。会员登录与身份记录无按日身份时，按取数日身份判定，两侧同一取法 |

### 新增用户 7 日留存率（M2）

对应决策项：活动位按玩家身份拆分

| 项 | 内容 |
|---|---|
| 指标定义 | 队列中注册后第 7 日有登录的人数 |
| 分母 | 队列人数：注册日落在队列窗口内的用户 |
| 对比方式 | 切换前后 |
| 对比窗口 | 切换前队列注册日 D-21 至 D-8，观察至 D-1；切换后队列注册日 D+1 至 D+14，观察至 D+21 |
| 数据来源 | 会员登录与身份记录 |

### 回流用户 7 日留存率（M3）

对应决策项：活动位按玩家身份拆分

| 项 | 内容 |
|---|---|
| 指标定义 | 队列中回流判定日后第 7 日有登录的人数 |
| 分母 | 队列人数：身份在队列窗口内变为回流的用户 |
| 对比方式 | 切换前后 |
| 对比窗口 | 同 M2 |
| 数据来源 | 会员登录与身份记录。无身份变更记录时，若标签「回流」按连续未登录天数判定，以满足该天数后的首次登录日推算回流判定日，两侧同一取法（推算规则以问题 11 答复为准）；两者均不具备时 M3 不取数 |

### 潜在流失回升率（M4）

对应决策项：潜在流失定向覆盖全部卡别

| 项 | 内容 |
|---|---|
| 指标定义 | 圈入用户中，下月储值额高于圈入当月储值额的人数；按普卡银卡、金卡至至尊卡两组分别计算 |
| 分母 | 圈入人数：圈入月最后一日标签「当月储值额小于上月储值额 50%」名单内、当日身份为其余（持续、VIP、黑名单）的活跃用户。取月末名单：标签若以当月 1 日起的累计储值与上月全月比较，月初名单会圈入多数付费用户；新增、回流身份切换后改走新建的活动弹窗，不计入两组 |
| 对比方式 | 切换前后，并以普卡银卡组为同期参照：该组在 ID10、ID11 下已有同一内容，其余身份的 ID5 内容也不变，切换后规则内容不变；金卡至至尊卡组为新覆盖人群。以两组各自前后差值之差作为定向效果 |
| 对比窗口 | 切换前组：D0 所在月往前第 2 个月月末圈入，观察下一个月；切换后组：D0 次日起第一个完整自然月（D0 为 1 日时取下一个月）月末圈入，观察下一个月 |
| 数据来源 | 潜在流失名单快照（写法见 C2 第四节）：两侧圈入日均有快照时取快照，任一侧没有时两侧均按 09 表4 重算；储值订单 |

### 潜在付费首储购买率（M5）

对应决策项：潜在付费沿用储值位首储礼包

| 项 | 内容 |
|---|---|
| 指标定义 | 窗口内购买首储礼包的人数 |
| 分母 | 窗口首日符合潜在付费定义（从未储值，且近 4 个月投注总额超过 10,000）、且窗口内有登录的用户数 |
| 对比方式 | 切换前后。该人群储值位配置切换前后不变，差值只反映同期变化，作为基线监测报告，不作为改动效果 |
| 对比窗口 | 储值类窗口内首储礼包对未购买玩家开放的日期；两侧开放日数不等时，较多一侧只取离 D0 最近的同等天数，分母的窗口首日改为所取日期中最早一日 |
| 数据来源 | 储值订单；投注记录。两侧「从未储值」「近 4 个月来的投资总额超过 10000」名单均按 09 表5 以窗口首日为截止日重算，不取标签留存 |

## 三、指标（依赖埋点）

### 破产位储值转化率（M6）

对应决策项：破产位排序以破产礼包优先

| 项 | 内容 |
|---|---|
| 指标定义 | 破产位弹窗曝光后，在该弹窗内完成购买的次数；按弹出礼包（首储礼包、破产礼包、独享礼包、其余）拆分；其余为限时加码礼包、惊喜三选一、生涯限购、每日礼包、平台限量/专属礼包 |
| 分母 | 破产位弹窗曝光次数 |
| 对比方式 | 切换前后 |
| 对比窗口 | 储值类窗口 |
| 数据来源 | 弹窗曝光与点击埋点；储值订单 |

埋点在切换前未覆盖破产位时，切换前一侧只能取破产礼包、独享礼包的窗口订单数，不构成转化率，两侧须用同一口径。

### 各人群人均每日弹窗曝光数（M7）

对应决策项：弹出总量按人群控制

| 项 | 内容 |
|---|---|
| 指标定义 | 人群内活动类规则的弹窗曝光次数之和（切换前 ID5、ID10、ID11；切换后 ID5、新增用户活动弹窗、回流用户活动弹窗、ID10）；按新增、回流、其余、潜在流失分别计算，与 02「弹出总量按人群控制」的活动类每日次数上限对照。ID6 曝光另行报告，不计入对照 |
| 分母 | 人群登录人日数：窗口内每日有登录的人群用户数之和 |
| 对比方式 | 切换前后 |
| 对比窗口 | 基本窗口 |
| 数据来源 | 弹窗曝光埋点；会员登录与身份记录；潜在流失名单快照：两侧窗口均有快照时取快照，任一侧没有时两侧均按 09 表8 重算。会员登录与身份记录无按日身份时，按取数日身份判定，两侧同一取法 |
