# 推送后台原型 · 运营走查（10/13）

我的身份：第一次看这套后台的运营，只看了页面截图（走查_01–18.jpg，走查_19 是页尾空白）。没展开任何「展开」块和附录，没卡到非展开不可。

整体感受：页首「按任务走一遍」和我的 7 件事几乎一一对应，我都是先看索引、再跳到对应页核对。没有它，25,000px 的长页会慢很多。原型里的「今天」是 10/12，下文都按这个日期算。

## 1. 潜在流失（两档）明晚 20:00 推播｜快
- 步骤：页 2 点「新建推播」→ 页 3 填内容 → 发送对象选标签群组「潜在流失（两档）7,880」→ 定时选 10/13 20:00 → 第 5 步看人数链：7,880 → 7,850 → 可触达 4,310 → 上限挡下 110 → 预计发出 4,200 条 → 先发「运营测试组（4 人）」，看逐号结果 → 点「确认排程」→ 回页 2，列表显示「已排程」。
- 犹豫：报给主管该用 4,310 人还是 4,200 条？「上限挡下 110」是拿今天的已收量去估明天吗？测试的第二个输入框没有标签，我猜要填会员编号。
- 没找到：无。

## 2. 礼包快到期自动提醒，礼包后台不再重复发｜一般
- 步骤：页 2 新建 → 页 4 选「按行为」，触发行为选「限时加码礼包快到期」，设剩 2 小时、勾「只发给尚未购买」→ 人数链 1,250 → 800 → 勿扰放弃 200 → 预计 540 → 点「确认启用」→ 离开推送后台，去页 12 礼包后台，看到两项已改只读，并指向 ID 31。
- 犹豫：页 2 里 ID 31「限时加码礼包未购买提醒」已经在运行。那这件事是不是早就做完了？我如果再建一条同触发行为的推播，会不会提示重复、会不会给同一人发两次？另外勿扰放弃占了四分之一，该不该改成顺延？
- 没找到：同触发行为的重复检测。

## 3. 回流玩家新增大厅弹窗并排第 1｜慢
- 步骤：页 9 点「新增」→ 页 10（这页画的是编辑 ID 14 的表单，新增只有一张小卡）→ 对象选「回流」→ 看到「与 ID 13 重叠 16,444 人，会命中两条」→ 添加排序项，拖到第 1 → 保存 → 页 16 核对纪录。
- 犹豫：我原以为「第 1」是这条规则排在所有弹窗前面，看了说明才知道排的是规则里面的项目，规则和规则之间谁先弹没写。命中两条后是两条都弹还是只弹一条？页 9 写着活动类靠排除互斥，那我是该给新规则加排除，还是直接改 ID 13？弹窗类型不知道该选哪个，弹窗规则也没有「发送测试」。
- 没找到：完整的新增表单；规则重叠后该怎么处理。

## 4. 推播上限改 3 条、深夜不发｜快
- 步骤：侧栏「频率上限」→ 页 11 推播 2 改 3 → 勿扰起点 00:00 改 23:00 → 保存，确认框显示改前改后 → 确认 → 页 16 有纪录。
- 犹豫：「深夜」按 23:00 算是我猜的。勿扰是推播、短信、FB、LINE 共用，看不出能不能只设推播。「游戏外合计 3 条」容易和推播的 3 条搞混。勿扰提前后，按行为推播会多放弃一些，确认框没说影响多少人。
- 没找到：这次改动对已排程、运行中推送的影响量。

## 5. 近 7 天发送、到达、点击并导出｜一般
- 步骤：页 13 选「近 7 天」→「各推送」页签看游戏外、游戏内两张表 → 下方「推送明细」逐条看 → 右上「导出 Excel」。
- 犹豫：两张表是按渠道汇总的；明细是按每条推送列的，但只有到达率、点击率，没有到达数和点击数，要进页 14 才看得到。说明里写「两张表一起导出」，明细会不会一起导出？iOS 不回传到达，汇报时得注明到达数只含 Android。明细的「游戏内推送」只有 1 条，和页 9 的 7 条弹窗规则对不上。
- 没找到：导出内容清单。

## 6. 玩家为什么没收到短信｜快
- 步骤：页 15 输入会员编号（也能用手机号查）→ 短信那一行显示「有手机号」、今日 0/1 → 收到记录筛「未收到」→ 找到 10/12 10:00 那条短信，原因是「服务商接口超时」。
- 犹豫：如果那天根本没给他发过短信，页面会显示什么？原型只画了「近 30 天无记录」的空状态。查到原因以后，也跳不到那条推送去重试。
- 没找到：从收到记录跳到单条推送的入口。

## 7. 部分失败只重发失败部分｜慢
- 步骤：按索引先去页 1「待处理」，结果那里只有 ID 44，是全部失败 → 看说明才知道部分失败算已完成，只计在「有失败」→ 页 13 明细找到 ID 38「已完成·部分失败 1,870」（页 2 还有一条 ID 36）→ 点「重试失败部分」，确认框列出可重试条数和截止时间 → 重试 → 页 14 看结果，页 16 看纪录。
- 犹豫：「有失败 1」看起来不像能点；列表的状态筛选没有「部分失败」，只能逐行看小字。ID 36 是 10/11 20:00 发的，截止却是 10/12 20:30，起算点没写。重试受不受勿扰和当日上限限制、短信重发要不要再计费，也都没写。
- 没找到：部分失败的集中入口。

## 最大的 5 个困惑
| 困惑 | 页 | 什么会有帮助 |
|---|---|---|
| 部分失败不进「待处理」，状态筛选里也没有这一项 | 页 1、2、13 | 待处理加「部分失败·可重试」一类，或状态加筛选 |
| 新弹窗规则和 ID 13 重叠后会怎样；「第 1」指规则内还是规则间 | 页 9、10 | 写明重叠的结果，给一个排除重叠群组的快捷操作，补上完整的新增表单 |
| 已有 ID 31 在运行，再建同触发推播会不会重复发 | 页 2、4、12 | 已有同触发行为的运行中推送时给出提示 |
| 最后一步的叫法不统一（可触达、预计发出、发给），单位有人、条、则、人次 | 页 3、6、7、13 | 统一成「预计送达 N 人」，并注明上限挡下是怎么估的 |
| 导出包含哪些表不清楚；明细缺到达数和点击数 | 页 13 | 按钮旁写明导出内容，明细补上绝对数 |
