# 判例 23：解释不言自明的内容，把读者当小学生

| 项 | 内容 |
|---|---|
| 类型 | 写法 |
| 你提出意见的时间 | 2026-10-12（同类：10/8「看着像在给小学生解释」） |
| 当时原文 | V4 目录页每章后的说明：「现在怎样，影响到谁」「要做到什么，为什么」「怎么改，哪些现有功能就能做」「怎么验收」 |
| 考试 | 待考 |

## 你的原话
「这个也介绍吗？感觉把读者当做小学生对待了一样，多余的篇幅」

## 错在哪
章名「现状与影响、目标、做法、验证」本身已说清各章讲什么，再加说明是重复，占篇幅、显得居高临下。写作标准已有「不铺垫」「指导意见、方法论导语、读者是谁这类元信息要删」。

## 改对后
目录只留编号、章名、页码；章名、版块名已能说清时，全稿删去解释结构、教读者怎么读的文字（读者从标题看不出某部分作用的不适用，见判例 40）。

## 抓到的判定（考试用）
章名、版块名已能说清时再加解释，判必须；读者从标题看不出某部分作用的不适用（见判例 40）。
