#### 4.1.17 模板、常用发送对象与营销档期（10/15 夜补充）

> 游戏外推送的内容模板、常用发送对象组合，以及「营销档期」的管理处；快显模板在快显页内，与游戏外分开。（10/15 夜补充）营销档期由推送、弹窗规则、快显共用，三处用同一字段、同一下拉。（v0.9.48）推送、快显选了所属活动时不再直接选档期，只读显示所在档期；不属于活动的才直接选（4.1.1「所属活动」）。
>
> 关键规则：模板与推送是复制关系，改模板不影响已建推送；「营销档期」只能从「营销档期」页签选，不能手输；有引用或有数据的只能停用或归档，从未使用的可删。

原型页 #10a（新增）；字段：[5.22](#s5-22)、[5.4](#s5-4) 序号 56–60。

**核心逻辑**

| 项 | 规则 |
|---|---|
| 入口 | （v0.9.47 改，原「侧栏游戏外推送下、「频率上限」上方」）侧栏「活动与配置」组第二项（活动与事件目录之下，4.1.2）为「模板」，页内三个页签：模板、常用发送对象、营销档期；快显模板在快显页内，字段相同，不与游戏外共用 |
| 模板 | 一个模板只用于一种推送方式；存内容（含图片）、默认跳转，可引用常用发送对象，可勾「随模板保存发送设置」（消息类别、本条不受频率上限的计入方式与原因、本条不受勿扰、有效期、适用平台、是否包含 VIP；不存发送时间）；跨推送方式用「复制为其他推送方式的模板」，按目标的字数上限截断，超出部分标红、不能直接用 |
| 从模板创建 | 新建表单推送内容块顶部「从模板创建 ⌵」，列当前推送方式启用的模板；选后填入内容、跳转、常用发送对象与（若有）发送设置，各字段仍可改 |
| 存为模板 | 新建表单底部「存为模板」，弹框填名称，可勾「同时保存发送设置」 |
| 复制关系 | 从模板创建后推送内容独立，改模板不影响已建、已排程的推送 |
| 常用发送对象 | 存群组、排除群组与是否包含 VIP，不存「名单」；新建表单「常用发送对象 ⌵」选后填入，可再改；引用的群组被停用时标红「群组已停用」 |
| 营销档期 | 「营销档期」的唯一管理处：名称不可重名，起止日期选填（只用于筛选与看板分组，不限制发送）；新建表单只能下拉选进行中的档期或「＋新建档期」（只填名称）；本期选填；用于按档期合并看数据、跨推送方式补位（4.1.1「排除前序推送已受理的人」）；「复制到其他推送方式」生成的草稿自动带同一档期；改名后已关联的推送随之显示新名；（10/15 夜补充）弹窗规则（5.12 序号 55）、快显（5.8 序号 21）也可选营销档期，定义、下拉与「＋新建档期」同推送；营销档期页签的「关联推送」改为「关联推送与规则」，有关联规则的档期同样只能归档<br>• 关联项目（10/18 资深同行评审后加，原列为后续，3.5）：营销档期加「关联项目」，从活动与事件目录的项目目录（4.1.20）多选，选填；只用于档期汇总的弹窗数据按项目归属（规则见 4.1.8「档期汇总」游戏内归属），不改项目本身、不影响发送与弹出；营销档期页签列表加「关联项目」列；改关联项目同其他字段，生成新版本、记操作纪录（5.22 序号 25）<br>• （v0.9.47 改定义）营销档期是跨多个活动的营销主题（如「10 月回流季」含周年庆、回归聚宝）；关联项目＝它包含的活动；所属活动（4.1.1）是关联项目的推送、快显、弹窗排序项自动算入该档期，不必逐条再选。凡按营销档期取对象的地方（档期汇总、列表档期筛选、停止本档期、「＋排除前序推送」可选范围、承接推送按档期）都按「直接选了该档期，或所属活动在关联项目里」取；上一句「只用于档期汇总的弹窗数据按项目归属」随之扩到推送与快显。一个活动的推送、弹窗、快显靠所属活动串起来，营销档期在活动之上合并看<br>• （v0.9.48）挂接收为一层：推送、快显只选所属活动；营销档期包含哪些活动只在本页签挂（关联项目）；只有「不属于活动」的推送、快显才在表单里直接选营销档期，选了所属活动的表单营销档期一行只读显示「随周年庆算入 10 月回流季」；弹窗规则的营销档期字段不变（4.2.1）。营销档期退为报表分组与筛选（档期汇总、列表档期筛选、停止本档期），对运营只记所属活动一套键；「＋排除前序推送」按档期取范围的规则不变（核心② 待定） |
| 删除与停用 | 模板：从未用过的可删，其余只能停用，停用后不出现在「从模板创建」下拉，已建推送不受影响；营销档期：有关联推送的只能归档，从未关联的可删；已归档的不出现在下拉 |
| 版本 | 模板、常用发送对象、营销档期每次保存生成新版本，可「恢复此版本」（生成新版本，确认框同 4.1.3.3）；已从模板创建的推送不受影响 |
| 筛选 | 模板按名称、推送方式、创建人、状态筛选 |
| 权限 | 运营可增删改；只读角色只看；新增、编辑、停用、归档、删除、恢复版本记操作纪录 |
| 范本（10/16 夜补充） | • 「模板」页签内加「范本」分组：运营负责人维护的示范配置，推播、短信各 1 条范本推送（含发送对象、排除、频率上限的示范设置），弹窗规则 2 条范本（大厅登录弹窗、破产弹窗）<br>• 弹窗新增规则页（原型页 #9）顶部「从范本新建 ⌵」：选后填入对象、排除、投放条件与示范排序项，名称前加「范本复制·」，名称未改不能保存<br>• 范本本身不能确认发送或上架；成本：现有可做 |
| 字段说明（10/16 夜补充） | 新建表单与弹窗规则编辑页的关键字段（发送对象、排除、本条不受频率上限、勿扰处理、优先级、互斥组、实验分流）旁加「?」，悬停显示一句说明与操作手册链接；说明文字为系统配置，可改（5.22 序号 24）；成本：现有可做 |

**异常与边界**

| 场景 | 处理 |
|---|---|
| 模板内容超出推送方式上限（如上限调整后） | 从模板创建后字段标红，校验同新建表单，改好前不能确认 |
| 模板引用的常用发送对象已删除 | 从模板创建时不带受众，提示「常用发送对象已删除」 |
| 模板里的跳转目标已下架 | 带入后按 4.1.3.2「点击跳转」校验 |
| 两人同时编辑 | 后保存的人提示「已被他人修改」，须刷新后重改 |
