|---|---|---|---|

- 每一次的结果按上表一次性推送的定义判定（已完成、部分失败、发送失败、无可发送对象），记在该次上，按次进总览待处理（4.1.2），不改变推送状态，也不影响之后各次。

- （v0.9.28）跳过下一次、暂停至：用于维护日等只停一两次的情况，不必停掉重建。跳过下一次：只跳过最近的一次，确认框写「10/16 20:00 第 1 次将不发送，之后从 10/17 20:00 继续；总次数不变」；暂停至：选日期（不晚于「重复至」），期间到点的各次不发送，到期自动恢复，状态仍为已排程，旁标「暂停至 10/20」，可「取消暂停」。被跳过的各次记「已跳过」，不进待处理；两项都记操作纪录，原因选填。

**各状态能否恢复**（v0.9.28；流转图见原型附录「状态流转图」）

| 状态 | 是否终态 | 能否恢复或改回 |
|---|---|---|
| 草稿 | 否 | 可编辑、删除；确认后进入已排程、发送中或运行中 |
| 已排程 | 否 | 可编辑（须重新确认）、停止；重复的定时可跳过下一次、暂停至；到点转发送中 |
| 发送中 | 否 | 不能修改，只能停止；发完转已完成或发送失败 |
| 已完成 | 是 | 不能恢复；可复制；有可重试条数时可重试失败部分（状态不变） |
| 发送失败 | 是（重试后有受理转已完成） | 可重试的在窗口内可重试；可复制 |
| 已停止 | 是 | 不能恢复，已发出的消息不撤回；可复制 |
| 已暂停（随活动撤下）（v0.9.47） | 否 | 随撤下记录整批恢复为已排程；恢复时发送时刻已过的转已停止、不补发 |
| 无可发送对象 | 是 | 不能恢复；可复制并改发送对象（定时的发送时间清空） |
| 运行中 | 否 | 可编辑（新版本）、暂停、结束 |
| 已暂停 | 否 | 可手动或到时恢复为运行中；可结束 |
| 已结束 | 是 | 不能恢复；可复制 |
| 已跳过（重复的定时某一次） | 是 | 只记在该次上，不改变推送状态；不补发 |

弹窗规则的上架中、已下架、停用、已删除能否恢复见 [4.2.1](#s4-2-1)「规则是否弹出」。

##### 4.1.3.2 新建（立即、定时）

> 立即、定时推送的新建表单，一页五块：推送内容、发送对象、发送时间、频率上限、确认与测试。（v0.9.25）消息类别移到推送内容块第一行；低频项收进第 4 块下方的「高级设置」折叠区；「确认与测试」块的提示分阻断、需确认、提示三级。
>
> 关键规则：确认后直接为发送中或已排程，没有审批；定时须在 3 分钟后、30 天内，可设重复（每天或每周几，至某日，最长 90 天），每次到点按群组当时的名单发；勾选「本条不受频率上限」须选计入方式并填原因；「本条不受勿扰」可单独勾选，须填原因（v0.9.28）。

原型页 #3；验收用例 T01、T10、T11、T14、T16、T17、T19、T29、T34、T35、T53、T54、T59、T60、T84、T85、T92、T359–T361（10/16 夜补充）；字段：[5.4](#s5-4)。

**交互流程**

1. 推播列表点「新建推播」，进入一页五块的新建表单；顶部步骤条显示每块当前状态，例：「已填／4,310 人／10/15 20:00／每人每天 2 条／通过」（勾选「本条不受频率上限」后第 4 块写「不受上限」）。
2. 推送内容：（v0.9.25）第一行先选消息类别（营销／服务通知／紧急，4.1.7「消息类别」；（v0.9.42）立即、定时不提供「活动提醒」，它只给迁入的系统活动提醒与玩家自身事件（事件锚点、排名变化）触发的按行为推送，4.1.7「活动提醒」），它决定适用上限、勿扰默认，短信还决定短信类型与可用字数，所以放在写内容之前；再填推送名称、标题（≤30 字）、内文（≤60 字），选填图片，选点击跳转；右侧同步预览 iOS 与 Android 通知样式。（10/15 夜补充）可先在内容块顶部「从模板创建 ⌵」带入模板，选营销档期（4.1.17）；底部「存为模板」。（v0.9.47）推送名称下一行选「所属活动」（4.1.1「所属活动」；点击跳转选了项目时自动带入），营销档期在它下面一行。（v0.9.48）所属活动必选、无默认，下拉第一项为「不属于活动」；选了活动时营销档期一行只读显示所在档期，选「不属于活动」时才可直接选营销档期。
3. 发送对象：选全部玩家、标签群组（可多选，下拉列出当前人数，其余输入名称搜索）或「名单」（粘贴或上传会员编号，显示匹配数与无效编号，见 4.1.1「名单」）；排除群组里黑名单、机器人与测试账号固定排除、不可删，VIP 名单默认排除、可删，其余可加（4.1.1「固定排除」）；下方逐层显示预计人数。（10/15 夜补充）可从「常用发送对象 ⌵」带入群组与排除；已选营销档期（（v0.9.47）含所属活动自动算入的档期）时可「＋排除前序推送」（4.1.1；v0.9.41 改：未选档期时可选本条发送前 24 小时内开始的推送，本条为重复的定时也可选）。（v0.9.44）群组下拉可按名称或所含标签搜索、按大类筛选，选项带群组人数 · 批次 · 状态 · 说明首句，最近使用置顶，底部可去标签群组设定新建（4.1.1「群组下拉」）；可勾「近期已登录不发」（4.1.1 三；（v0.9.45）标签群组为「名单算出后又登录过的不发」，其余为「发送前 N 小时内登录过的不发」）；选「名单」时可加只限群组、另存为手动标签（4.1.1「名单」）；（v0.9.45）排除前序推送可选按行为推送（近 N 天收到过）。
4. 发送时间：选立即或定时（按行为见 4.1.4）；定时填日期时间，可选重复（不重复／每天／每周几，至某日；见下方「重复」），下方列出各次发送时间与总次数；勿扰处理默认「顺延到勿扰结束」（选项文字按频率上限页当前设置写出结束时刻，如「顺延到 08:00」），可改为「放弃发送」。（v0.9.25）勿扰的顺延、放弃与「本条不受勿扰」都在本块勿扰一行：「本条不受勿扰」勾选框可单独勾选、须填原因（v0.9.28 改，不需先勾「本条不受频率上限」），勾选后勿扰处理显示「不受勿扰（勿扰时段内照常发送）」，不能再选顺延或放弃。发送时间下方只读显示「当天已排」（同推送方式与跨推送方式合并一处，4.1.1 四）。（v0.9.42）发送时间下方可选「合并组」：同一开始发送时刻的不同推送方式放进同一组，按渠道顺序每人只发一则（4.1.4「合并组」，5.4 序号 97）。（v0.9.47）定时可选「相对活动时间」：按所属活动的开始、结束加偏移写，例「开始前 16 小时 → 10/23 20:00」，活动改期时自动跟随（4.1.20「相对活动时间」）；从活动总览新建时默认用相对时间。
5. 频率上限：只读显示本条适用的上限汇总，例「推播每人每天 2 条 · 最小间隔 30 分钟 · 勿扰 00:00–08:00 顺延（在「频率上限」页设置）」，可点「去修改」。（v0.9.25）原在本块的消息类别移到推送内容块第一行，「当天已排」移到发送时间块，「本条不受频率上限」（默认不勾；勾选后选计入方式、填原因）移到高级设置。
5a. （v0.9.25）高级设置：第 4 块下方一行「高级设置 ▸」，默认收起；有项不是默认值时标题写「已设 N 项」（见下方「高级设置」）。
6. 确认与测试：显示校验结果（v0.9.25 起按「确认块提示分级」分三级列出）、预计人数逐步减少（（v0.9.44）各层写人数名称与批次，排除后、可触达两层拆明细，见下方「合并」）、摘要表（发送方式、发送对象、频率上限、勿扰时段、标题、内文、点击跳转）；可发送测试（见 4.1.5）。（v0.9.47 改）「发送测试」按钮移到底栏，与其他五种页面同一位置；本块标题下常驻一行测试状态与上次结果，例「本条尚未发送测试」或「上次测试 10/22 18:05 · 3／3 已收到」，没测不拦（4.1.5「测试状态」）。
7. 点确认按钮：立即为「确认发送」，定时为「确认排程」。确认后直接为发送中或已排程，没有待审批状态；操作纪录记一条「确认…」。（10/15 夜补充）命中高风险条件时先弹高风险确认框（见下方「高风险确认」），确认后同上。

**异常与边界**

| 场景 | 处理 |
|---|---|
| 可触达为 0 人 | 「当前群组没有可发送的玩家，不能确认」，确认按钮不可点 |
| Facebook、LINE 按钮链接未填 | 输入框与预览里的按钮标红；「确认与测试」块列为未通过项 |
| 短信内文超过上限 350 字（含品牌前缀、退订说明与短链，按 67 字串接为 6 则；10/16 夜补充） | 计数变红，校验不通过 |
| 短链服务不可用 | 保存时提示「短链生成失败，请稍后再试」，不能确认；已排程的短信、Facebook、LINE 在开始发送前再生成一次，仍失败则按服务商未受理·可重试处理 |
| 服务商受理后退回 | 计入发送，不计入到达；（v0.9.40）只有短信有（运营商失败回执），Facebook、LINE 不设此项（4.1.1「五」） |
| 短信服务商余额用完（10/16 夜补充） | 按「通道额度耗尽」：不消耗重试次数，剩余挂起，列入总览待处理「发送挂起」，充值后继续发送剩余或放弃（4.1.1「八」4） |

**接口需求**

| 接口（建议） | 输入 | 输出 |
|---|---|---|
| `POST /api/sms/preview` | `smsBody` | 替换短链后的内文、`charCount, segmentCount` |
| `POST /api/links/track` | `channel, url` | 短链服务的跳转链接模板；发送时每位收件人生成独立追踪码，点击时记录后跳到原链接，用于按玩家统计点击 |
