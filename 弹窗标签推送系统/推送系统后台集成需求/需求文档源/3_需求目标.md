## 3 需求目标

<a id="s3-1"></a>
### 3.1 目标

| 目标 | 做到什么 |
|---|---|
| 目标 1：统一入口 | 全部推送在推送统一后台配置和发送；各推送方式选发送对象用同一套标签群组，每人每天上限、数据统计按同一套规则 |
| 目标 2：按人群发 | 每种推送方式按标签群组选发送对象，可排除群组；立即、定时另可按名单（会员编号）发；按行为推送发给触发的玩家，群组只作可选限定 |
| 目标 3：每人每天有上限 | 每种推送方式每人每天各有上限，游戏外、游戏内分开计；游戏外推送在勿扰时段不发 |
| 目标 4：数据查得全 | 两层各按自己的指标统计；按推送方式、人群、单条推送、日期查看并导出；拿不到的数写原因，不估算 |
| 目标 5：操作省事、少出错 | 发送前看到预计人数与拦下人数；先发测试账号；发送状态可查、可停止，失败可重试；能查单个玩家收到了什么 |
