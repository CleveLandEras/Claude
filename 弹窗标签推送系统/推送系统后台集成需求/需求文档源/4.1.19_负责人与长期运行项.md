#### 4.1.19 负责人与长期运行项（10/16 夜补充）

> 推送（游戏外四种与快显）、弹窗规则、标签群组各有负责人，默认创建人，可转移；「长期运行项」列表按负责人列出仍在运行的项，可批量转移；提醒改发负责人。
>
> 关键规则：负责人只决定提醒发给谁、列表归谁，不改权限；转移只改负责人，不生成推送或规则的新版本；每条转移记操作纪录。

原型页 #10c（新增）；验收用例 T249；字段：[5.25](#s5-25)、[5.1](#s5-1) 序号 25、[5.12](#s5-12) 序号 60、[5.23](#s5-23) 序号 15。成本：小改动。

**核心逻辑**

| 项 | 规则 |
|---|---|
| 负责人字段 | 推送与弹窗规则新建时默认创建人，表单内可改为任一运营角色账号；列表加「负责人」列与筛选。标签群组的负责人即 4.3 的「维护人」，由标签系统维护，本后台只读 |
| 长期运行项 | 侧栏「推送日历」下方「长期运行项」：列运行中与已暂停的按行为推送、未到截止的重复的定时、上架中的弹窗规则、运行中的快显、被推送或弹窗引用的标签群组；（10/16 夜补充）另列三类，用于交接：已排程的一次性推送（建议默认值勾选显示）、草稿、下架中的弹窗规则（后两类在筛选「含草稿、下架中」勾选后显示）；每行：类型、名称与 ID、负责人、创建人、最后修改（时间、人）、到期日（生效结束或重复截止，未设写「长期」）、近 7 天发送或曝光；（v0.9.47）加「所属活动」筛选（4.1.1），筛出某活动的全部对象：推送、快显按所属活动，弹窗规则按排序项含该项目 |
| 提示 | 负责人账号已停用或 90 天未登入的标红「负责人不可用」；到期日在 7 天内的标黄 |
| 批量转移 | 按负责人筛选后勾选或全选，「转移负责人」选新负责人（运营角色账号），确认框按类型列条数；一次最多 200 条；每条记一条操作纪录，带同一批次号。标签群组不在本页转移，链到会员标签设定<br>• （v0.9.47）按活动整体转移：按所属活动筛选后全选，「转移负责人」一次转该活动的全部推送与快显；弹窗规则含其他活动排序项的，确认框单列并默认不勾，写「规则 ID 13 还含其他 5 个活动的排序项，转移会改整条规则的负责人」（5.25 序号 13）；（v0.9.48 改）按活动转移时弹窗规则一律单列、默认不勾，含其他活动排序项的逐条写「该规则还含其他活动的排序项：活动类·新增、回流…」；勾了才整条转：弹窗规则的负责人是整条规则的负责人，常驻规则多由弹窗运营负责，整条转走后到期、巡检提醒会改发给接手的推送运营 |
| 转移记录与转回（10/16 夜补充） | • 本页「转移记录」页签按批次列：批次号、时间、操作人、原负责人 → 新负责人、条数、代理至<br>• 「整批转回」：把该批中仍归新负责人的条目转回原负责人；期间被再转给他人的跳过并列出，新负责人自建的不在批次里、不动<br>• 转移时可填「代理至 YYYY-MM-DD」：到期当天通知新、原负责人转回，不自动转回<br>• 转回同样每条记操作纪录，带新批次号并注明「转回批次 B1012-03」 |
| 提醒改发 | 重复的定时每期内容提醒与截止提醒、按行为异常、引用失效巡检、弹窗到期提示改为发给负责人；负责人不可用时发给运营负责人；告警收件人设置不变，另抄送对象的负责人 |
| 权限 | 运营可转移；客服、只读只看 |

**异常与边界**

| 场景 | 处理 |
|---|---|
| 新负责人为只读或客服角色 | 不在下拉里，不能选 |
| 转移中有条目被他人同时编辑 | 负责人照常转移，编辑不受影响 |
| 创建人离职 | 创建人保留原值不改，只改负责人 |

**接口需求**

| 接口（建议） | 输入 | 输出 |
|---|---|---|
| `GET /api/long-running` | `ownerId, type, dueWithinDays` | `items[{type, refId, name, ownerName, ownerAvailable, createdBy, lastModifiedAt, lastModifiedBy, dueAt, last7dVolume}]` |
| `POST /api/owners/transfer` | `refs[{type, refId}]`、`newOwnerId`、`delegateUntil`（选填，10/16 夜补充） | 转移结果、`batchId`；权限：运营 |
| `GET /api/owners/transfers`、`POST /api/owners/transfers/{batchId}/revert`（10/16 夜补充） | 转回时无 | 批次列表；转回结果、新 `batchId`、已跳过的条目 |
