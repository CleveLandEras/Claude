## 5 后台需求

| 项 | 说明 |
|---|---|
| 修改内容 | 推送统一后台为新页面；弹窗、玩家查询、操作纪录、礼包后台「推荐礼包设定」在现有页面上改，字段表的备注写「现有」「新增」「改」 |
| 默认值 | 规则说明里写「建议默认值」的，按此值上线，运营可改 |
| 权限控制 | 运营可编辑；只读角色只看（见 4.1.11） |
| 兼容性 | 现有字段的程序命名写「沿用现有」，不改名 |
| 必填 | 是＝必填；否＝选填；条件＝满足规则说明中的条件时必填；—＝系统生成或只读显示 |
| 数据类型 | 比率为 String（百分比，保留 1 位小数）；时间为 String（HH:mm）；JSON 结构写 List<…>；（10/16 夜补充）所有日期、时间与 DateTime 字段按台湾时间（UTC+8）录入、显示与判断，服务端按 UTC 存时接口须带时区，界面不设时区选择 |
