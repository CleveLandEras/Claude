# 改动清单（需求评审版原型 · 界面重做 · 2026-10-23）

结论：按运营扫读路径重做了视觉层级——日历能按日扫排期并辨认上限/顺延；定时状态改成「一行主状态 + 一行次要」；弹窗上架空状态补齐。未改业务规则与示例数据含义。

## 改了哪些

### A. 日历周视图（02a / 02g）

1. **事件卡分层**  
   - 普通：极浅蓝灰底 `#F7F9FC` + 浅边框；warn（上限/顺延）：极浅橙底 `#FFF8F0` + 左侧色条。  
   - 名称字重 700，时间次要（浅灰、字号更小）；高度 34px，左右留白。  
   - 原因：上轮只加白底描边，普通与异常同质，扫不过来。

2. **今天列与表头**  
   - 今天列表头浅蓝底 + 蓝色「今天」胶囊；日列浅蓝底加强；竖线 `#E8EAED`。  
   - 原因：打开周视图要先落在「今天」。

3. **底部说明 → 摘要条**  
   - 原先两行灰色 `.fold` 改成两条紧凑 strip（今天橙左边、明天蓝左边），正式口径不变。  
   - 原因：说明像页脚附注，不像运营摘要。

4. **页眉节奏**  
   - `10/21–10/27 · 今天起 7 天` 改为 `.rangebar`，与 capbar / 日历间距对齐。  
   - 勿扰灰条保留，文案不变。

### B. 定时 / 条件触发列表（02e / 02f）

1. **状态列主次**（02e）  
   - 主状态一行：发送中蓝加粗、已发完灰、未开始默认。  
   - 次要（顺延、上限拦截人数）统一 `.sub` 一行；过长靠 title 悬停保留全文（展示只留关键数字句）。  
   - 原因：单元格里堆两三段理由，像小作文。

2. **行高 / 数字 / 选中**  
   - 维持约 48px；数字列右对齐；选中行浅底保留。  
   - 筛选行 chip 高度与输入框对齐（28px），避免左右高低不齐。

3. **02f 状态空单元格**  
   - 进行中行补浅灰「进行中」，与筛选 pill 对称（同 10a「上架」逻辑）。  
   - 原因：空单元格看起来像漏字。

### C. 弹窗规则 / 内容（10a 及同源页）

1. **上架空状态**  
   - 进行中/上架行状态列写浅灰「上架」，与草稿/已结束对称。  
   - 同步：10a2、10a3、10c、10c2、10c3。

2. **优先级降噪**  
   - 优先级列更窄更浅灰；规则名加粗、ID 浅灰保持。  
   - 页签与右侧状态 pill、调整优先级同一基线（原有 flex-end，未拆结构）。

### D. 克制通扫

- `_弹窗.css`：状态主次、`.sub` 截断、筛选对齐、优先级色。  
- 查询页（19）、新建（02）、06b：结构已完整，未大拆。  
- 未为改而改堆阴影。
