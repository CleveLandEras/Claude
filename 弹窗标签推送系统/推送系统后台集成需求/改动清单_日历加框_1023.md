# 改动清单（需求评审版原型 · 2026-10-23）

结论：日历每条推播已改成带边框的白底卡片；顺带统一了上限条外框与定时表选中行底色。未改业务规则与示例数据。

## 改了哪些

1. **02a_推播列表.html · 日历条目加框（核心）**  
   - `.gcal .ev`：白底 `#fff`、`1px solid #E4E7ED`、圆角 4px、内边距略增、极轻阴影 `0 1px 2px rgba(31,35,41,.06)`。  
   - `.ev.warn`：保留左侧 inset 色条（顺延/上限拦截），并与外框阴影并存。  
   - 卡片高度 30px，左右留白，同日多条互不糊成一团。  
   - 原因：原先 `border:0; background:transparent`，看起来像漂在格子上的字。

2. **02a / 02g · 日历外框与日列分隔**  
   - `.gcal` 加浅边框与圆角；日列、表头日格加 `#EEF0F3` 竖线。  
   - 原因：周视图缺边界，日与日不好扫。

3. **02a / 02g · 日历下方说明行间距**  
   - `.fold` 与日历间距、字号略调。  
   - 原因：原先贴得太紧。

4. **02g_推播停止确认.html**  
   - 同步同一套日历卡片样式（停止确认叠在日历上，避免一页有框一页无框）。

5. **_弹窗.css · 上限信息条**  
   - `.pw.plain .capbar` 恢复浅底+边框（与非 plain 一致）。  
   - 原因：plain 页被洗成透明无框，和「每条要有边界」不一致。

6. **_弹窗.css · 定时列表选中行**  
   - `table.pt tr.on` 恢复极浅底 `#F7F9FC`（不再全透明）。  
   - 原因：选中行几乎看不出，和列表扫读习惯不符。
