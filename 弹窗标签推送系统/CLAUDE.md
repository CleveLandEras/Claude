# 弹窗标签推送系统

- 新对话先读 `先看这里.md` 顶部「当前状态与交接」，再读 `规则与交接/标准体系.md` 第〇节（规则入口）。
- 与 Dk 协作的工作原则：本机在 `~/.claude/CLAUDE.md`（所有文件夹都加载）；云端会话读仓库里的 `_底座/全局规则_快照.md`。共用的验收做法（分角色验收）、验收清单、纠正记录在 `_底座/`。`规则与交接/记忆_快照/` 是 10/20 的旧快照，只作出处，不再按它工作。
- 汇报格式技能本机用 `~/.claude/skills/report-format/`；`.claude/skills/report-format/` 是给云端会话的副本，推送前同步成同一版。
- 文档里写的 `/Users/decheng.huang/claude/弹窗标签推送系统` 指本仓库根目录；`_scripts/` 下的脚本已改为按自身位置找项目目录。
- 只能在 Dk 的 Mac 上用的工具：`_scripts/pl_pptx渲染.sh`、`_scripts/pl_网页截图.swift`（渲染、截图）。pptx 只用 `_scripts/pl_pptx渲染.sh` 在 `_versions/渲染/` 导出，换目录会触发授权弹窗。
- 仓库只放接着干活要用的上下文，不放的内容见 `.gitignore`（旧版本、截图、旧临时脚本、已作废的归档）。
